# 前端组件选型指南

> 适用范围：新增页面与组件。本文明确每个场景的唯一实现，禁止重复造轮子。
> 违反本文的模式会被 `npm run check:style` 拦截。

## 设计令牌

- 颜色、字体、字距、行高只用全局令牌，禁止字面字体栈与十六进制色。
- 间距只用刻度（0.125、0.25、0.5、0.75、1、1.5、2、2.5rem），禁止离群间隙与像素间距。
- 边框只用语义令牌：强（可交互表面）、柔和（表格与结构分隔）、细（内部控件）；选中态用强调边框。禁止手写三色 1px 实线。
- 关系域色板与画布样式共享同一令牌，图例禁止自定颜色。
- 断点统一使用 480、768、900（抽屉）、1024、1200 五档语义，不新增断点。

## 反馈类

- 页面级错误使用块级错误横幅，支持可关闭能力，关闭后清空对应错误状态。
- 表单与工具内部错误使用行内错误，紧贴触发操作的位置展示。
- 阻塞整块内容的等待使用加载态组件；结果列表等可预估形态的等待使用骨架屏组件，不手写占位与闪烁样式。
- 空数据使用空态组件，不手写提示文本。空态支持次要提示行，用于补充操作指引。
- 行内信息与告警使用通告组件，按语义选择信息或告警变体；过期数据统一使用告警变体。需要附带操作时使用操作插槽，不手写横幅样式。
- 需要用户确认的异步操作结果使用消息通知；表单校验错误使用行内错误，不在页面内重复实现关闭按钮。两者边界：通知面向已完成的操作回执，行内错误面向未提交的输入问题。
- 模态确认使用弹窗组件，标题、内容与操作区分离，支持 ESC 关闭，不手写遮罩与对话框样式。

## 按钮与输入

- 所有可点击操作优先使用基础按钮，按主次选择主要、次要、危险、幽灵变体。
- 视图切换统一使用页签组件，按语义选择变体：路由或分区导航使用下划线变体，同一数据源的视图切换使用分段变体。不手写页签容器与切换样式。
- 列表选择器（关系域开关、候选列表、模块芯片）统一使用可选芯片组件，选中态与禁用态由组件承载，域配色通过插槽传入，不自造列表按钮样式。
- 富内容行（项目条目、关系条目、社区）统一使用全局可选行样式，横向行直接使用，纵向卡片加纵向修饰；选中态由该样式承载，每项补充无障碍选中标记。禁止自造项目条目、社区按钮、关系条目样式。
- 行内文本链接（如死信文件路径）统一使用全局文字链样式；展开收起统一使用全局展开开关样式。
- 分页统一使用分页组件，传入当前页、总数（未知传空）、前后回调与禁用态，不手写分页行。
- 表单字段二选一：纵向标签加控件加错误提示使用基础输入组件；密集过滤行与自定义布局的裸输入使用全局单行文本样式。两者不混用、不新增别名。密集过滤行使用窄宽修饰控制输入宽度。
- 下拉框统一使用全局下拉样式，不自造选择框样式。
- 复选行统一使用复选字段组件；开关式设置继续使用开关组件，附带说明文字时将说明放在组件下方。不手写复选标签样式，不使用原生复选框裸排。
- 大号搜索框是独立的 hero 样式，全局类为搜索 hero，仅用于顶层搜索入口；过滤行输入使用单行文本样式。
- 代码编辑文本域使用全局深色样式，仅用于工具代码输入；浅色配置编辑器保留域内样式。
- 纵向标签加控件使用工具字段组件，横向紧凑场景使用工具字段的行内模式，不手写行内字段样式。
- 小尺寸操作按钮使用超小尺寸，图标按钮需提供无障碍标签。

## 布局与展示

- 页面头统一使用页面头组件，标题、副标题与操作区分离。
- 布局铬（侧栏与顶栏）的配色由布局铬令牌驱动，项目选择器只有一套实现，不按位置分叉样式。
- 列表过滤与操作行使用工具栏组件，左侧放筛选，右侧放操作。
- 卡片用于承载独立信息块，可点击卡片需明确悬停反馈；卡片集合使用全局卡片网格，不自写多列网格与断点覆盖。
- 总览指标统一使用指标卡片组件，置于指标网格内，不手写指标卡样式。
- 细节键值统一使用描述列表组件（字符串数据）或全局描述行样式（富内容如徽章），纵向用条目、横向用行，不手写详情网格与键值行样式。
- 在线与健康状态统一使用状态点组件，不手写状态圆点。
- 徽章用于状态与分类展示，日志级别映射到全局语义色；过期标记统一使用告警徽章。
- 表格使用全局表格与表格容器，保证横向滚动与表头样式一致；运维页同样使用该容器与运维令牌，不自造深色表格与弹窗。
- 长列表使用全局滚动列表与截断工具，不手写列表重置与省略样式。
- 键盘按键使用全局按键样式，不重定义。
- 分栏布局使用分栏组件，进度展示使用进度条组件。

## 工具与图表

- 新增工具页面组合工具骨架、工具表单行、工具操作区与工具字段，错误、表单、结果分区明确，不手写表单行样式。
- 工具字段承载标签与输入框的组合，宽字段使用宽模式，横向场景使用行内模式。
- 调用链展示只有一套实现，图模式与列表模式共用同一数据源。
- 图表视口操作使用基础按钮，布局选择使用全局下拉样式的下拉框。
- 日志相关页面使用卡片、工具栏、表格与徽章组合，不引入第三方原子化样式。

## 禁止事项

- 禁止新增裸按钮与裸输入样式，禁止复制关闭按钮、页签、切换按钮样式。
- 禁止引入与全局设计体系冲突的第三方原子化类。
- 禁止在组件内重复定义全局已有的按钮、输入框、徽章、表格、分页、状态点、描述、卡片网格样式。
- 禁止新增横幅、页签、芯片、弹窗、表单行、表格、分页、状态点、描述列表、卡片网格、可选行、文字链、展开开关、复选行、骨架屏、按键的局部样式；对应场景必须复用既有组件或全局样式。
- 禁止重定义搜索 hero 类名，禁止新增运维深色令牌。
