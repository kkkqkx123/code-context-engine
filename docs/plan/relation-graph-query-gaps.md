# 关系图查询：潜在问题与缺失能力

> 范围：盘点当前关系图查询系统的设计缺陷与功能空白，为后续演进提供输入。

---

## 1. 潜在问题

### 1.1 内存压力

- **全量内存索引**：`RelationIndex` 全部驻留内存（`DashMap` + `RwLock<HashMap>`），无磁盘溢出或分页机制
- **大项目风险**：十万级实体 + 百万级边时，内存占用可能达到数十 GB
- **快照全量加载**：`LayeredSnapshotIndex` 反序列化时全量载入，冷启动延迟高

### 1.2 增量更新粒度

- **快照整体替换**：当前增量更新是 base + delta 整体合并，非真正的图增量维护
- **delta 膨胀**：频繁小更新导致 delta 链变长，查询时需逐层合并
- **无局部失效**：单个文件变更可能触发大范围快照重建

### 1.3 边权重缺失

- **等权边**：所有关系边无权重区分，无法表达调用频率、依赖强度
- **影响分析精度**：BFS 传播时等权处理，无法区分核心路径与边缘路径
- **无时序信息**：无法回答"某时间点的依赖状态"或"依赖关系何时引入"

### 1.4 关系类型粒度模糊

- **CallbackCall vs HigherOrderCall**：回调调用与高阶函数调用边界不清
- **ChainedMethodCall**：链式调用拆分为多条边还是一条复合边，未明确
- **GoroutineCall / DeferredCall**：Go 特有类型，其他语言的并发原语无对应建模

### 1.5 动态分派与多态

- **虚函数调用**：C++/Java 虚函数表调用无法精确解析到具体实现
- **接口动态分发**：Go interface、Rust trait object 的调用目标不确定
- **反射调用**：Java/C# 反射、Python `getattr` 动态调用无法静态建模

### 1.6 条件编译

- **分支依赖未建模**：`#ifdef` / `#[cfg]` 不同编译条件下的依赖关系被扁平化
- **平台特定代码**：`#[cfg(target_os)]` 等条件编译边丢失

---

## 2. 缺失能力

### 2.1 跨语言/跨进程边界

- **FFI 调用**：Rust FFI、C ABI 调用链无法跨语言追踪
- **RPC/REST**：gRPC、HTTP API 调用关系未建模
- **消息队列**：Kafka、RabbitMQ 等异步消息传递的隐式依赖

### 2.2 灵活图查询语言

- **固定端点限制**：当前仅提供预定义端点，无法表达任意图模式
- **缺少类 Cypher/Gremlin 查询**：用户无法自定义多跳过滤、模式匹配
- **路径过滤**：无法表达"仅经过测试代码的路径"或"排除某类节点的路径"

### 2.3 社区检测与聚类

- **模块度分析**：无 Louvain / Label Propagation 等社区检测
- **核心-边缘结构**：无法自动识别系统核心模块与边缘模块
- **分层抽象**：无法自动聚合成更高层次的架构视图

### 2.4 时序与版本维度

- **图快照版本化**：无法对比两个时间点的图结构差异
- **依赖演进**：无法回答"某依赖何时引入/移除"
- **变更影响回溯**：无法回溯某次提交对图结构的影响

### 2.5 权重与度量

- **边权重**：调用频率、依赖强度等量化指标
- **节点中心性**：PageRank、Betweenness Centrality 等重要性度量
- **耦合度度量**：模块间耦合/内聚的量化分析

### 2.6 子图匹配与模式查询

- **结构模式匹配**：查找符合特定拓扑模式的子图（如"所有 A→B→C 且 A→C 的三角形"）
- **反模式检测**：自动识别循环依赖、上帝类等架构坏味
- **架构约束验证**：验证"领域层不得依赖基础设施层"等分层约束

---

## 3. 优先级建议

| 优先级 | 项目 | 理由 |
|--------|------|------|
| P0 | 边权重（调用频率） | 提升影响分析精度，实现成本低 |
| P0 | 动态分派建模 | 多态是实际代码的核心场景 |
| P1 | 条件编译分支 | C/C++/Rust 项目必需 |
| P1 | 图查询语言 | 解锁灵活分析，减少端点膨胀 |
| P2 | 跨语言 FFI | 微服务/多语言项目需求 |
| P2 | 社区检测 | 架构治理高级能力 |
| P3 | 时序版本化 | 需要底层存储重构 |
| P3 | 子图匹配 | 计算复杂度高，场景较窄 |
