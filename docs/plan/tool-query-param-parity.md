# Tool 与查询图搜索参数补齐方案

本文以前一轮全量接口整理与调用方覆盖分析为输入，收敛为可直接执行的修改计划。后端线协议为基准，前台请求层与存储层已就绪、命令行基本完整，剩余工作均为小幅补齐。所有改动遵循原模块内修改原则，不新增替代模块，不做兼容层，代码文件使用英文，文档使用简体中文。

## 范围与非目标

本次处理调用方参数补齐，不涉及后端检索语义、索引管线与存储后端的任何改动。

明确不做的事项及原因：搜索请求中的项目路径字段前台不透传，前台以全局项目选择器为唯一项目来源，逐请求覆盖只会制造状态歧义；搜索条数前台不设直接输入框，后端无偏移参数，前台累计拉取加客户端切片是既定分页模型；图查询的域过滤前台保持纯客户端可见性控制，服务端下钻会破坏增量展开的完整上下文，属既有设计；图邻域与分支的分页偏移、实体详情页的关系过滤面板属于产品形态范畴，请求层与存储层均已透传就绪，界面控件待后续单独排期；协议工具面保持策展形态，图遍历与版本代际等诊断能力仅走超文本接口；项目管理与摘要生成等管理类命令的缺口不在本次查询工具范围内。

## 阶段一 命令行正确性修正

第一项移除压缩命令上被接受但实际被忽略的项目标识参数，该参数无对应的后端字段，属于误导性设计，直接删除而非保留。第二项修正图邻域命令方向参数的帮助文案，服务端接受方向别名，但规范取值为双向与内外两种朝向，文案应与前后端保持一致。第三项为索引全量命令补齐忽略模式参数，逗号分隔解析后透传至索引请求体，终结请求体中写固定空值的现状。

## 阶段二 命令行对等能力补齐

第一项为关键词搜索命令补齐版本代际参数，可选透传至后端请求体，用于诊断场景下 pin 住特定索引代际，缺省保持当前代际行为不变。第二项为聚合搜索补齐逐子查询权重能力，现状只有按检索来源划分的四组类型级权重，同类型内无法差异加权。方案为在四组查询值上支持权重后缀写法，带合法后缀时取逐项权重，否则回落到类型级权重，空子查询报错文案保持英文。

## 阶段三 前台页面对等能力补齐

第一项为关键词搜索工具面板补齐版本代际输入，空值表示缺省，请求层类型契约已含该字段，仅需面板透传。第二项为图探索器的路径模式补齐深度输入，现状写固定深度，存储动作已接受深度参数，仅需种子条加数字输入并在页面装配时向下透传。第三项为实体详情页的两点调用路径补齐深度输入，现状使用默认值，存储动作已接受深度参数，仅需表单加数字输入并透传。

## 核验

全部阶段完成后集中核验一次：后端侧跑完整编译检查与受影响包的单测，前台侧跑类型检查。每阶段不单独起编译，以节省系统资源。

## 实施结果

三阶段已按上述划分落地。阶段一移除了压缩命令的无效项目标识参数，修正了图邻域方向文案，为索引全量命令补齐了忽略模式透传。阶段二为关键词搜索补齐了版本代际参数并收敛为参数结构体以满足参数个数 lint，聚合搜索支持查询值上的权重后缀写法并附单测覆盖。阶段三为关键词工具面板补齐版本代际输入，为图探索器路径模式与实体详情页调用路径补齐深度输入。核验一次通过：受影响包编译检查无警告，单测全部通过，前台类型检查零错误零警告。
