# Gin 全管线差距修复方案（2026-11-05）

日期：2026-11-05
范围：Go Gin  fixture 暴露的碎片更多加文本稀释问题
上游结论：问题清单见同期基线差距分析文档，切分效应与文本效应已分离，测试干扰为放大器

## 1. 目标

在不改变评测口径与对齐语义的前提下，让全管线在含干扰变体下不再系统性输给直接切分与原文对照，让干净变体下的领先保持稳定。成功标志为模糊与语义查询的局部下滑收敛，向量分组路原文优势收窄，相关层不再同步走低，大区间目标小切口单块覆盖率回升。不追求单切口全面反超，允许个别拥挤性波动。

## 2. 设计原则

先治碎片再治文本，碎片减少后文本纯度自然回升。合并只救真正无检索价值的碎片，不捆绑独立语义方法。区间只声明文本实际承载的行，不声明整组整函数。模板只在保留精确信号的基础上概括意图，不以泛化代替签名。评测与对齐逻辑不动，不通过放宽覆盖或折叠对齐键掩盖问题。

## 3. 修改方案

### 3.1 大组按方法完整性切分

现状是统一词数预算把大结构体组连环切散，长方法在体内被硬截断，组头概览挤占成员预算。调整为以方法边界为优先切分单位，长方法独占一块，块内再按语义完整性换行，禁止在条件分支与错误处理中间截断。组头概览独立成块，不计入成员预算，成员块只装成员文本。预算数值不变，只改变边界选择与预算归属，宁可块数略增也要保证单方法单块可检索。涉及组切分策略与句边界回退逻辑，预期分发主干与路由树类大目标在小切口的单块覆盖率回升。

### 3.2 收紧小方法合并

现状是五十行跨度内短方法无差别合并，导致八方法同块，目标仅占块六分之一。调整为仅合并无独立检索意义的碎片，如纯声明、空实现、单行转发，具备独立签名与独立行为的短方法一律独立成组。合并块上限收紧为两到三方法或两百词以内，超限即拆。合并时保留各成员完整签名句，不做从属改写，平级方法不再表述为某方法之子。涉及小碎片合并器候选判定与组转换模板，预期格式化写入、响应写入、JSON 方法等短目标的块纯度回升，原文独胜现象收敛。

### 3.3 修正标题与关键词归属

现状是合并块标题取组名或首成员，与块内多数方法名不一致，渲染方法块标题为 Cookie 即典型。调整为标题取块内文本实际承载的主实体，多方法块标题列出全部成员名，关键词取各成员精确标识符的并集并保留原始大小写。标题与关键词只描述块内文本实际出现过的实体，不再沿用整组头名。涉及块标题生成与关键词提取，预期限定查询误标导致的零召回消除。

### 3.4 词项保留精确形态

现状是标识符统一小写拆分，模糊查询失配。调整为在保留拆分词的同时保留原始大小写精确词，限定共现保留父子限定形态，标题保留完整接收者加方法名。调用链中的精确调用名保留原形，不归一化。测试文件中的同名小写调用不再与实现精确词同权竞争，模糊的大小写与词缀变化重新成为区分信号。涉及词项模板与关键词提取、文本清洗，预期模糊查询的原文优势收窄，限定查询在含干扰变体下回稳。

### 3.5 向量保留关键调用细节

现状是短方法摘要过度泛化，动宾搭配丢失，如字符串方法丢 format 参数，响应写入方法丢 WriteHeaderNow 调用。调整为短方法块保留完整签名句与核心调用句，如渲染调用、头部设置、错误写入、内容类型设置等，不压缩为泛化意图句。长方法块保留主干控制流与关键分支，不只留头尾。合并块内各方法摘要长度均衡，不让长邻居淹没短目标。涉及向量模板与组描述生成，预期语义短查询的向量排名回升，向量分组路原文领先收窄。

### 3.6 统一区间与文本的归属

现状是片段声明整组区间而文本仅为摘要或分片，延续块头部简介计入覆盖。调整为片段只声明其文本实际覆盖的行，合并块声明并集但要求文本包含对应成员摘要，概览卡声明并集而普通片段不扩大，延续块头部简介不计入覆盖。空区间保持为零。涉及区间归属计算、合并区间并集、概览合成逻辑，预期声称可覆盖而排不上的脱节消除，组覆盖与单块覆盖的差距如实反映文本质量而非归属夸大。

## 4. 影响面

改动集中在解析后三阶段，不涉及解析器与语言检测。块数上大组碎片略增而小组合并减少，总体块数基本持平或微降，向量与词项成本无量级变化。排序上短目标纯度上升而大目标单块覆盖上升，测试干扰下实现块排名预期回升。分组覆盖因区间收紧而更诚实，组检索器短期可能小幅波动，但长期与单路差距收敛。

## 5. 验证标准

形态层面要求引擎与节点大组的方法体内截断消失，上下文 JSON 簇与字符串簇不再八方法同块，从属误标消失，块标题与块内主实体一致，片段区间与文本行基本一致，空区间为零。单测层面覆盖方法完整切分、合并候选收紧、区间归属、标题限定形态。集成层面要求双路径块数不膨胀，共享区间不新增。

指标层面要求含干扰变体下模糊与语义查询的系统性下滑消失，向量分组路全管线与原文差距收窄，相关层不再同步走低，大区间目标小切口单块覆盖率回升，干净变体下全管线对直接切分的领先保持。验证顺序为文本转储、分块数据生成、离线评测，先看块形态再看指标，避免以指标倒推形态。

## 6. 验证结果

本次落地三项最小修改：小碎片合并排除有文档实体并将批量上限收紧为三，跨组合并块标题合并命名，成块 viable 行数由五降为三。评测前三项目基线已备份，验证按导出、数据生成、离线评测全量重跑。

金项目全管线在含干扰变体下全面反超直接切分，词项、分组词项、向量、分组向量小切口召回分别领先约零点零六、零点零二、零点二二、零点一八，全管线对原文亦全面领先，文本差距收敛。块形态上合并标题恢复多成员署名，向量块数上升约一成，稀释下降。

搜索项目全管线向量与分组向量分别领先直接切分约零点一二与零点零三，分组词项差距由负零点零九收敛至负零点零三，原文差距收敛。

Web 项目全管线向量与分组向量领先直接切分，词项小切口回落约零点零七但三查询在大切口全部恢复，且仍领先直接切分，判定为拥挤性波动而非系统性退化。结论为碎片与稀释主因已收敛，剩余工作为大组方法边界硬截断的后续优化。
