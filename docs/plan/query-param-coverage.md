# 查询与图搜索参数覆盖问题清单

本文整理后端已支持的查询能力与各调用方（命令行、模型上下文协议、前台页面）的参数覆盖差距，并给出修复任务划分。细节以代码现状为准，后端为基准。

## 基准能力

后端统一检索支持单查询与多子查询聚合两种形态，覆盖向量、关键词、混合、摘要四种检索来源，附带分数门限、目录前缀、通配符包含排除、内容类型排除、文件分类包含排除、重排开关与候选数、查询意图改写、调用图邻居展开等调节手段。实体名检索支持全文语法与种类过滤。关键词检索支持分页偏移与词项连接方式。关系查询覆盖函数详情、直接调用与被调用、单向多跳调用链、两点调用路径、继承与实现、分类统计。图查询覆盖十个端点，包含单点邻域、两点路径、显式子图、连通分支、全量导出、文件级影响、实体级影响、环检测、结构关系、模块关系，通用过滤包含域、关系类型、外部边开关与分页。工具查询覆盖符号、引用、定义、折叠与批量折叠。

## 调用方差距

### 命令行

单查询命令缺失文件分类包含排除与查询意图，请求体中写固定空值。聚合搜索命令缺失项目路径、分类包含排除、重排开关与候选数、查询意图，子查询权重写固定值且仅支持关键词与向量两种来源。图命令中邻域、路径、子图、分支、导出五个子命令缺失关系类型过滤，实体影响子命令缺失作用域。实体命令中直接调用、被调用、调用链仅透传方向，未透传深度、分页、测试排除、目录前缀、排除文件、域与外部边开关，两点路径仅透传深度，实体搜索缺失项目路径。工具命令中关键词搜索仅暴露数量，未暴露偏移与词项连接方式，引用查询未暴露代码片段与实体信息开关，批量折叠仅接受纯文本列表，丢失逐项语言与配额设置及全局默认值。

### 模型上下文协议

语义检索工具仅暴露数量、目录前缀与展开开关，检索来源写固定默认值，其余过滤与重排、意图参数全部丢失。关键词检索已覆盖偏移与连接方式，符合预期。直接调用、被调用与调用链工具固定为调用域且排除外部边，未暴露分页与过滤，调用链仅暴露方向与深度。批量折叠逐项缺失配额与模式字段。图遍历按设计保持为超文本专属，未暴露为协议工具，本次不做改动。

### 前台页面

前台位于独立目录，之前回复误判为缺失，特此纠正。前台请求层类型契约由后端文档生成，但当前生成产物滞后于后端，缺失查询意图、展开开关、稳定符号标识与展开统计等新增字段，需要重新生成。搜索状态管理缺失查询意图与展开开关的透传，过滤面板缺失对应控件。图请求层仅覆盖邻域、路径、子图、分支、导出、文件影响六个端点，缺失实体影响、环检测、结构关系、模块关系四个端点，已覆盖端点也缺失关系类型、外部边开关、域与分页等过滤透传，图状态管理同样受限。实体请求层仅透传方向与深度，缺失分页与过滤透传。工具页面中引用工具缺失上下文行数与片段开关透传，关键词工具缺失偏移透传，折叠仅支持单条，未提供批量折叠入口。

## 修复任务划分

单查询命令补齐分类与意图参数。聚合搜索命令补齐项目路径、分类、重排、意图与权重参数，并补齐混合与摘要子查询来源。图命令补齐关系类型过滤与实体影响作用域。实体命令补齐分页与过滤透传及实体搜索项目路径。工具命令补齐关键词偏移与连接方式、引用开关、批量折叠逐项与全局参数。协议语义检索补齐来源、分数、通配符、分类、重排与意图参数。协议批量折叠补齐逐项与全局配额模式参数。协议调用类工具补齐分页参数，保持调用域约束不变。前台重新生成类型契约，补齐搜索意图与展开透传及控件，补齐图四个缺失端点与过滤透传，补齐实体分页过滤透传，补齐工具缺失透传与批量折叠入口。每项改动保持原模块内修改，不新增替代模块，不做兼容层。

## 后续核验与遗留收尾

前一轮改动后集中核验发现四类残留问题，均已在本轮收尾。代码文件统一使用英文，文档使用简体中文。

向量引擎告警方面，水平归约函数内的内层作用域在新版工具链下已无必要，原因是相关向量内建函数现为仅需目标特性的安全函数，直接移除内层包装即可。标量兜底的分发闭包可直接写为函数路径。跨架构一致性测试中对回退模块的调用在非目标架构下本就是安全函数，改为按目标架构分别处理。

前台死信页面方面，移除未使用的徽标引入与不再被调用的格式化函数。选中与展开集合改用框架提供的响应式集合类型，直接原地增删与清空，不再经由拷贝赋值触发更新。

历史缺口复核发现三处本轮补齐项。聚合搜索在子查询为空时的报错文案改为英文，满足代码英文规范。协议调用链工具补齐分页参数并改用后端已有的分页查询，默认取全链以保持原有行为，仅在显式传参时分页。向量引擎的向量指令内核用法补入统一风险文档。

前台存储层补齐服务端过滤透传的剩余部分。图存储的邻域、展开、子图、路径、概览、分支动作均接受可选过滤并向下透传。实体存储的函数详情与调用链动作均接受可选关系过滤并向下透传。均为末尾可选参数，不影响现有调用。

明确暂缓一项。图页面中新端点与服务端过滤的界面控件属于功能范围，请求层与存储层已就绪，页面接线待后续按产品形态单独排期。
