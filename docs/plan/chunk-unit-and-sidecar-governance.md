# 召回差距修复：分块单位与侧车治理

日期：2026-11-04
范围：`flask` 为主，`ripgrep` 为对照；延续问题文档中首轮最小修复的验证结论
上游结论：体提取去重与词项去碎改变了块数形态，但 `G1Q6` 家族向量仍失败、`G2Q18` 向量仍只有原文成功、词项聚合差距未收敛

## 1. 背景

首轮验证确认三件事。第一，文档重复消除有效但只覆盖侧车回退路径，主路径的原生重复仍然存在。第二，跨组合并与微碎救援 symmetric 化后词项块数大幅下降，但目标查询未恢复，说明块数不是主因。第三，形态指标健康（空区间为零、共享区间为零），失败集中在单位错位与文本稀释，而非索引损坏。

本轮只解决机制已证实、影响面可预期的问题；机制不清或收益不确定的方向留作后续实验，不进入本轮实现。

## 2. 剩余问题分析

### 2.1 侧车正文混入签名尾与原生文档字符串

证据在词项审查转储中可直接看到：同一成员的后半分片以原生签名尾开头，后接带标记语言的完整原生文档字符串，最后才是真正的调用代码。向量路对应分片同样携带该重复块。两路共享侧车装配，因此两路同时被污染，这是实现层面的单一根因，不是两路各自的问题。

该重复块的来源是行为事实的区间落在实体代码体起点之前。装配逻辑会跳过注释类事实与文档字符串陈述事实，但判断依据是事实自带的文本快照；一旦事实区间本身起于签名区而文本快照与源文不一致，跳过条件即失效，重抽取把签名尾与原生文档字符串一并带回。装饰器存在时更容易触发，因为实体区间起点早于定义行。

后果有三层。成员文本虚增约上百词元，二十余行的小方法因此超出单块预算，被迫在成员内部切分。分片携带的原生标记与签名残片稀释了真正行为信号的权重。行窗口映射按文本权重分配，被重复块推偏。

### 2.2 小成员被迫在内部切分

`register_blueprint` 二十余行对应约六百词元的成员文本，超出向量体预算，被迫按句切成两片。单片无法覆盖标注区间，需要两片同时进入前列；两片各自的嵌入又都不够聚焦，排序上被淹没。原文切片保持单片，单命中即恢复。这与上一节是同一因果链：重复块是成员超限的主要可压缩部分，去掉后成员大概率回到单块预算内。

### 2.3 小实体跨阶段行级重复与样板稀释

`func flash` 审查文本显示同一赋值语句出现两次（一处带句点一处不带），分别来自模板关系行与侧车正文；版本变更样板与调用列表进一步拉长文本。原文三十二行全部是行为，嵌入聚焦；自然语言版本混入重复与样板后，语义查询的排序落后于原文。本轮不深入模板重构，仅在计划中记录，原因是跨阶段去重涉及行窗口映射归属，需要单独设计。

### 2.4 词项长方法多分片与索引竞争

超长方法在任何实用预算下都必然多分片，评测要求多片共现。自然语言比原文长，同方法分片更多；同时全量词项块数多于原文基线，排序竞争更激烈。上一节的去重会同步缩小两路文本，减少分片数与竞争，但长方法本身的多分片属性不会消失。若本轮后词项聚合差距仍大，说明需要成员边界优先的切分策略或在线实体聚合，属于后续工作。

## 3. 本轮设计

### 3.1 代码体起点守卫

原则：侧车只拥有代码行为，签名与文档属于模板。装配侧车事实前，先按实体区间与源文算出代码体起点：跳过空行与装饰器行，跳过定义头（含多行签名，以行尾冒号或右括号加冒号为结束标志），再跳过前导文档字符串块（含单行与多行形式）。任一步骤不匹配即回退为区间起点，保证未知语言与异常形态下行为与原来完全一致。

事实过滤规则：整体落在代码体起点之前（含边界）的事实丢弃；横跨起点的事实将其抽取起点钳制到代码体起点。控制流事实与行为事实统一适用。缺口填充与尾部逻辑不变，因为保留下来的事实全部位于代码区之后，缺口不可能再含有文档字符串。

该修复只改侧车装配一个位置，不新增模块，不改模板、切分、合并与评测。回退默认值保证非 Python 语言与异常实体零行为变化。

### 3.2 本轮明确不做

评测语义不变，不放宽覆盖与贡献规则。预算数值不变，不调阈值。模板层不动，不重排摘要结构，不删除版本信息。跨阶段行级去重与成员边界优先切分留作后续，前者需要先明确侧车文本的行归属规则，后者需要评估切分点移动对窗口映射的影响。

## 4. 验证标准

单测层面：构造一个区间横跨签名与文档字符串直达调用的行为事实，断言侧车正文不含签名残片与原生文档标记，只保留调用代码；装饰器加多行签名加多行文档字符串的组合形态同样覆盖；非定义开头的实体区间回退为无过滤。

集成层面：重跑两语言场景导出，要求 `register_blueprint` 成员文本不再含有原生签名尾与原生文档字符串块；词项对应分片同样干净。

指标层面：`flask` 向量 `G1Q6` 家族至少恢复为单块覆盖或多片共现可达；`flask` 词项扰动查询（以 `dumps` 为代表）观察是否随成员聚焦而恢复，不强求；聚合上向量路保持领先、词项差距收窄为加分项，不作为门禁。`ripgrep` 为对照，要求无回退。

## 5. 后续工作

跨阶段行级去重（模板关系行与侧车正文的归一化包含判断，需先明确侧车文本行归属）。成员边界优先切分（超限成员的细分点选择与窗口映射联动）。词项长方法策略（若差距持续，评估成员级聚合或预算内重排）。`G2Q18` 类语义稀释若持续，转向模板样板治理实验。
