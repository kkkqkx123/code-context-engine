# emb 语义鸿沟：解耦评估与按实体切块（2026-11-12）

## 1. 背景

上一轮三处改动（函数体上限、调用行封顶、文件角色行）的多 K 复核显示：方向正确但实现需调。top20 及以上四个项目一致上升、近重复块大幅消除（gin duplicate_text_share 0.103→0.006），说明意图优先的版式方向成立；但无事实兜底的头部截断过于激进，造成 top5 与个别语义题回归（G2Q20 由二到零为确定性损失）。去重收益来自间隙回填移除，回归风险主要来自头部截断，两者应解耦评估。

本轮基线为 `ref/backup/emb-perentity-baseline-2026-11-12`（与 v1 输出逐文件一致，35M，benchmark 五项目加 chunks 五项目），后续对比以此为准。

## 2. 病因回顾

语义鸿沟的主因是同块兄弟稀释：目标实体只占块的约一到两成，其余是兄弟方法的文档与函数体。BM25 对长度不敏感，稠密向量是平均池化，兄弟内容直接把目标向量拖走。九个 gap 查询中，请求体绑定目标是四方法块的尾巴，模板渲染目标被排在两个长方法之后。

次因是无事实兜底截断误删深部 token：无控制流与行为事实的实体整段函数体被截断到头部约一百五十 token，部分查询的区分词恰在尾部，导致 top5 回归与个别语义题由二归零。

## 3. 设计方案

### 3.1 解耦：保留间隙回填移除，撤销全局头部截断

间隙回填移除是去重收益的来源，保留。有事实时向量路仍跳过间隙与尾部回填，只保留控制流与行为事实片段；无事实时向量路恢复完整函数体，与词项路一致，不再截断到头部。这消除 top5 与深部 token 回归，同时保留近重复块消除效果。

### 3.2 按实体切块（主改动，仅向量路）

现状切块器在两路共用同一分组逻辑：携带自身文档的成员按理独立成块，但极短成员（自然语言代价低于块下限且源码不足三行）会被打回上一组合并，同名重载也会合并。BM25 侧该行为合理（一行碎块无检索价值）。向量侧则不同：稠密平均池化下任何兄弟合并都是稀释。

细化规则（仅向量路）：携带自身文档的成员一律独立成块，不再因极短而打回合并；无文档且源码不足三行的残渣仍向后合并；相邻同名重载仍合并（共享同一声明身份，拆散会打散查询必须在同一单元命中的调用体）。词项路逻辑不动。

### 3.3 保留项

文件角色行保留（跨语言题已见效）。调用行封顶保留（中性，待固定向量复测）。词项路全部不动。

## 4. 变更范围与护栏

只改转换原模块内向量路两处：富化阶段的无事实回退（恢复全文），切块器的成员分组（向量路文档成员免于打回合并）。词项生成、词项清洗、评测与对齐口径、既有预算数值一律不动（仅删除此前新增的头部截断预算，不动既有预算）。词项文本逐字节一致仍是硬护栏；BM25 行零翻转；A/B 对比必须排除重嵌抖动带。

## 5. 验证计划

形态验证先于数值验证：导出四语言，确认无事实目标恢复完整体、自带文档的极短成员各自成块、文件角色行仍在、词项全项目逐字节一致。数值验证走完整链路：数据重生五个项目，离线评测全部跑通，综合 top5/top10/top20/top50 与逐查询翻转。回归门槛为三项目无严重退化且词项行零变化；期望为 top5 回归修复、长尾增益保持、gap 查询翻转。若翻转幅度落入抖动带，如实记为未证实。

## 6. 执行记录与多 K 复核

本轮改动两处，均为向量路：无事实实体恢复完整函数体（删除此前新增的头部截断预算）；向量路自带文档的成员不再因极短而打回合并，仅无文档且源码不足三行的残渣向后合并，相邻同名重载仍合并。词项路全部不动。

形态符合设计：块数上升（gin 1224→1269，media 3657→3709，ripgrep 2135→2362，once_cell 155→180，flask 692 基本持平），近重复块份额不变；词项文本全项目逐字节一致，BM25 五项目零翻转。

### 6.3 结论与方向判断

切块安全但去稀释未转化为翻转：ripgrep 增加二百余块而 emb 零翻转，说明按实体切块不破坏既有命中，是安全的结构性改进，为后续更细切分留出空间。但兄弟稀释的解除没有带来 gap 翻转，gin 三题与 media 两题纹丝不动，说明剩余 gap 的瓶颈不在版式而在命题缺失（意图真空）：文本里根本没有查询要的命题，切得再纯也变不出信号。

恢复完整体部分兑现：once_cell top5 由零点四四回到零点六二，证实头部截断确曾误删深部 token；但 gin top5 未回升，说明 gin 的 top5 回归另有来源（间隙回填移除或抖动），头部截断不是唯一病因。

once_cell 的 reshuffle 是小语料加哈希向量下的高敏感表现，单块与分组口径涨跌互现，跨语言回落与 fuzzy 回升并存，不宜过度解读；其 top5 大幅回升与 top10 回落并存，恰是抖动带的形状。

如实记为部分证实：切块安全性得证，去重收益保持，top5 修复兑现一半；gap 闭合仍未发生。版式优化已近收益递减，剩余 gap 需命题级输入（文档补全、来源追溯），而非继续调切分。

## 7. 回退评估（2026-11-12 补记）

问题：本轮两处改动（恢复完整体、向量路文档成员免打回）是否整体退化、是否应回退。结论：不回退，保留。依据如下。

### 7.1 分组口径同样中性偏正

emb_group 全管线 R_s：gin top5 R_r 加一（G2Q13 语义由一到二）、top20 减一，净持平；media top5 R_r 加一；ripgrep top10 加一（G2Q14 由零到一）、top30 R_r 加一；flask 全同；once_cell 全 K 上升（top5 加零点二五、top10/20/30/50 全升）。三项目正向、一持平、一涨跌互现，无系统性退化。

### 7.2 once_cell top5 是广谱修复而非抖动

top5 逐查询：单块路七题由零到一（五 fuzzy 两 qualified），仅 G2Q10 减一；分组路十题由零到一。七到十个查询同向翻转远超一到四个查询的抖动带，证实头部截断确曾误删深部 token，恢复完整体兑现了本轮首要目标。回退将重现该损伤。

### 7.3 借项全在抖动带内或有对冲

gin top20 减一、ripgrep top30 R_r 减一，均为单查询量级；once_cell 单块路六负集中在小语料哈希向量的高敏感区，且分组路四胜零负对冲、top5 大胜。九个 gap 无新增。硬护栏完好：词项逐字节一致、BM25 五项目零翻转。

### 7.4 结构性前置收益

ripgrep 增加二百余块而单块路零翻转，证明按实体切块不破坏既有命中；命题级渲染需要纯实体块才能避免兄弟污染，回退将使下一阶段重做切块工作。

### 7.5 诚实保留项

gin top5 的上一轮回归未被恢复，说明其病因是间隙回填移除或抖动而非头部截断，留待命题级阶段用不依赖深部 token 的信号覆盖；once_cell 单块路跨语言回落提示文件角色行密度变化敏感，命题级阶段固定向量复测时一并观察。
