# 视图与服务映射

## 布局形态

主窗口采用侧边导航加可停靠面板。导航项与前端路由一一对应，图标语义与前端保持一致；
工作区默认布局按高频任务组织（检索、图谱、实体、索引），运维类面板默认收起但可从导航打开；
布局版本化，默认布局变更时递增版本号并重置过期持久化布局，避免旧布局指向已不存在的面板。

窗口壳层只做一件事：根据连接状态在连接配置页与工作区之间切换，并在两者之上保持同一套
窗口铬。连接配置页只收基地址与可选令牌，不做用户名口令形态；进入工作区后状态栏显示基地址
与健康探测结果，探测失败时标红但不踢回连接页。

## 前端路由到面板的映射

- 项目页对应项目面板：列表、创建、详情、配置读写与重载、语言模型配置概览。
- 索引页对应索引面板：全量、增量、单文件解析、摘要生成与索引统计，长任务显示进度与结果。
- 搜索页对应检索面板：单查询与聚合查询，复用表格与结果标签页形态。
- 实体页对应实体面板：详情、调用与被调用、调用链与调用路径、继承与实现、分类统计。
- 图谱页对应图谱面板：邻域、路径、子图、连通分量、导出、影响分析、环检测、结构与模块视图，
  并承接检索结果的一键送入。
- 工具页对应工具面板：折叠、压缩、诊断、关键词检索、符号、引用与定义。
- 存储页对应存储面板：清空、按文件或实体删除、批量删除、索引统计与存储状态。
- 健康页、指标页、监视页对应运维面板组：健康、三路诊断、指标文本与历史、监视启停与状态。
- 配置页对应配置面板：服务端配置信息、校验与重载。
- 日志页在桌面端已有独立面板（`views/logs_view.rs`），服务划分归入"日志"资源，工具/存储面板不动。
  契约与客户端方法见 `10-canvas-and-log-contract.md` 第 5 章；轮询、文件确认与配置热改见
  `11-backend-necessity-and-remaining-work.md` 第 4 章。
- 运维页（死信与重试队列）对应任务面板：列表、重试与确认。
- 摘要页能力并入索引面板与实体面板，不单独成面板，避免单字段面板。
- 网关的供应侧能力（本机文件枚举与推送）不在桌面端重复实现，桌面端只做远端任务的触发与观察。

## 服务划分

服务按资源一切分，与客户端模块对齐：项目、索引、检索、实体、图谱、工具、存储、监视、
健康、指标、配置、任务队列。每个服务是面板与客户端之间的唯一中介，持有分页游标、
历史记录与结果缓存。历史记录上限收敛，保证落盘体积可控。批量导出（如表格导出）放在服务层
实现，视图只触发。

## 分批范围

首批完成壳、导航、设计 token、主题、设置、连接与健康探测，以及检索、图谱、实体、索引、
项目五个高频面板。次批补齐工具、存储、监视、健康、指标、配置与任务队列面板。托盘、密度切换、
语言切换随首批落地；深色外观仅当 Web 侧引入深色主题后跟进，不提前自创。
