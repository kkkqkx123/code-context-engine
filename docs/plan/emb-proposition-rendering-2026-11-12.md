# emb 命题级输入：事实→命题句渲染（2026-11-12）

## 1. 背景与立项依据

v1 与 v2 两轮版式优化（函数体上限与回退、调用行封顶、文件角色行、按实体切块）已验证：长尾判别力上升、近重复块消除、切块安全、once_cell top5 广谱修复。但九个语义 gap 纹丝不动：gin 三题（请求体绑定、模板渲染、格式化输出）、media_server 两题（分发、会话头解析）、ripgrep 一题（读流搜索），其余三题已在 v1 翻转。

根因判定：剩余 gap 是意图真空而非版式问题。目标块文本等于身份行加调用表加原始代码，原始代码只陈述做法（赋值、分支、位运算），从不陈述意图；查询是命题（编码头、绑定请求体），文本里没有对应命题。切分再纯也变不出信号。下一阶段必须加分子：把已抽取的事实库存翻译成命题。

本轮基线为 `ref/backup/emb-perentity-baseline-2026-11-12`（v2 产物），后续对比以此为准。

## 2. 设计原则

渲染而非生成：所有命题句的实质词（实体名、分支条件、被调者、操作数标识符）必须原样来自该实体自身的 fact 文本、签名或元数据；模板只提供封闭骨架动词，不许自由文本。这是可审计性与无幻觉的边界。

只动向量路：BM25 是词面匹配不需要命题，词项路保持原始全文；命题句只进入向量文本。词项文本逐字节一致仍是硬护栏。

替代而非并存：emb 路事实片段以命题形式出现，不再保留无修饰的原始代码 dump；并存会加长分母，稀释刚提纯的信号。

## 3. 主改动：事实→命题句渲染

位置：转换原模块向量路富化阶段（当前 `build_extra_text` 的 emb 分支）。

映射关系（kind 到句式，动词封闭表）：分支与匹配沿用已有分支锚并补条件命题；错误效应渲染为报告错误命题；数据绑定按右值形态区分（调用右值得出自调用命题，非调用右值得出自标识符命题）；返回渲染为返回命题；循环渲染为遍历命题；数据查询渲染为查询命题。位运算与纯控制流终端（break/continue）不渲染，保留代码或降权。

版式：命题句置于身份行之后、代码体之前；每实体封顶八句（与调用锚同量级）；去重；无事实实体不受影响（v2 已恢复完整体）。

## 4. 可选项：无文档实体的借命题

仅当实体自身无文档时，附加父容器文档首句作为上下文行并置于尾部。属出借而非虚构，但有稀释子信号风险，需固定向量 A/B 验证；落抖动带即回退。默认关闭或默认开启由实现时单测成本决定，文档中如实记录选择。

## 5. 本轮不做事项

调用边单独命题化不做：调用点命题已被事实渲染覆盖（赋值与守卫形态均在 fact 中），调用行保持现有封顶去噪形状即可，不再扩展。

用法 harvesting 不做：从同文件调用点与测试用例收集实参类型与字面量（如某类型曾被传入绑定函数）属跨实体信息注入，需反向调用索引并评估回归，风险超出本轮预算，留待再下一阶段。

import harvesting 不做：与用法 harvesting 同属跨实体信号增强，一并延期；文件角色行保持现状。

签名命题化不做：把签名翻译成接受与返回句子的信息增益低且易引入模板噪音，签名保持代码形态。

## 6. 变更范围与护栏

只改转换原模块内向量路一处（富化阶段的 emb 渲染；若启用借命题则加组转换器一处）。词项生成、词项清洗、切块器、评测与对齐口径、既有预算数值一律不动。新增上限常量与既有锚点同量级并在设计中记名。

护栏：词项文本逐字节一致；BM25 行零翻转；命题句无新词单测（分词后实质词必须出自输入）；A/B 必须固定向量或多次重生取均值，落抖动带记为未证实。

## 7. 验证计划与下一阶段评估依据

形态先行：导出四语言，人工核对九个 gap 块是否出现对应命题句、命题句实质词是否可溯源、词项全项目逐字节一致。

数值验证：数据重生五项目，离线评测跑通。回归门槛为三项目无严重退化且词项行零变化。期望为 gap 翻转，尤其是 gin 三题与 media 两题；once_cell top5 保持；gin top5 上一轮回归是否被不依赖深部 token 的命题信号覆盖，作为附带观察项。

评估结论只取三档并如实记录：证实（超出抖动带的 gap 翻转）、未证实（落抖动带）、证伪（引入确定性回归则回退）。本档文档即下一阶段评估的比对基准。
