# 项目配置管理系统设计文档

## 1. 背景与问题

### 1.1 当前架构的问题

当前系统存在以下核心问题：

1. **Engine在初始化时固化配置**
   - Engine是单例，在服务器启动时创建一次
   - 配置被"固化"在Engine初始化时，无法支持多项目
   - 所有请求都使用同一个配置

2. **项目配置加载但未使用**
   - `Settings::init_for_project()` 加载并存储了项目配置
   - 但Engine从未调用 `Settings::for_project()` 获取项目特定配置
   - 项目配置实际上被忽略了

3. **API传递project_id但未用于配置加载**
   - API层接收 `project_id` 参数
   - 但只用于数据过滤，不用于动态加载配置
   - 无法实现真正的项目隔离

### 1.2 服务端应用的核心需求

作为服务端应用，应该支持：

```
HTTP Request → 提取project_id → 动态加载该项目配置 → 执行操作
```

而不是当前的：

```
Server Start → 加载单一配置 → Engine固化配置 → 所有请求共用同一配置
```

## 2. 设计方案

### 2.1 核心设计原则

1. **全局项目注册表** - 内存中维护所有已加载项目的配置（缓存）
2. **配置文件独立存储** - 每个项目的配置存储在独立的TOML文件中
3. **SQLite存储元数据** - 仅存储项目基本信息和配置文件路径
4. **懒加载 + 缓存** - 首次访问时加载配置，之后从内存读取
5. **热更新支持** - API触发配置重载，立即同步到内存和磁盘

### 2.2 架构概览

```
┌─────────────────────────────────────────────────────┐

│                                                      │

│  ...                                                 │

```

### 2.3 为什么选择JSON而非BLOB或TOML？

| 方案 | 优点 | 缺点 |
|------|------|------|
| **JSON文件** ✅ | - 人类可读，便于调试<br>- serde_json已有依赖，无需新库<br>- 解析性能优秀<br>- 通用性强，易集成 | - 不支持注释<br>- 比TOML稍冗长 |
| **TOML文件** | - 更适合手写配置<br>- 支持注释 | - 需要`toml` crate<br>- 解析性能较差<br>- 不适合程序化序列化 |
| **SQLite BLOB** | - 事务一致性<br>- 单一存储位置 | - 不可读，难以调试<br>- 无法手动编辑<br>- 序列化/反序列化开销大<br>- 不适合频繁变更 |
| **rkyv二进制** | - 性能最优<br>- 零拷贝反序列化 | - 完全不可读<br>- 调试困难<br>- 版本兼容性复杂 |

**决策理由：**
1. **已有依赖** - 项目已使用`serde_json`（通过serde），无需引入新库
2. **性能优秀** - JSON解析速度远快于TOML（约2-3倍）
   - serde_json: ~50-100 MB/s
   - toml: ~20-40 MB/s
3. **配置丢失不是根本性问题** - 可以重新生成
4. **解析开销小** - JSON解析通常在亚毫秒级（<1ms for typical config）
5. **可读性和可维护性** - 虽然是文本格式，便于运维和调试
6. **热更新场景友好** - JSON文件格式稳定，易于管理
7. **生态成熟** - serde_json是Rust生态中最成熟的JSON库

## 3. 数据模型设计

### 3.1 SQLite Schema

```sql
-- 项目元数据表
CREATE TABLE IF NOT EXISTS projects (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    root_path TEXT NOT NULL UNIQUE,
    config_file_path TEXT NOT NULL,  -- 相对或绝对路径，如 ".cce/config.toml"
    language TEXT,                    -- 主要编程语言
    extensions TEXT,                  -- JSON数组，如 '["ts","tsx","js"]'
    exclude_dirs TEXT,                -- JSON数组，如 '["node_modules","dist"]'
    respect_gitignore INTEGER DEFAULT 1,
    ignore_patterns TEXT,             -- JSON数组
    last_indexed TEXT,                -- ISO 8601格式
    created_at TEXT NOT NULL,         -- ISO 8601格式
    updated_at TEXT NOT NULL,         -- ISO 8601格式
    
    INDEX idx_root_path (root_path),
    INDEX idx_name (name)
);

-- 可选：项目状态跟踪（用于监控）
CREATE TABLE IF NOT EXISTS project_status (
    project_id INTEGER PRIMARY KEY,
    status TEXT NOT NULL,             -- "active", "indexing", "error", "disabled"
    last_error TEXT,
    error_count INTEGER DEFAULT 0,
    checked_at TEXT NOT NULL,         -- ISO 8601格式
    
    FOREIGN KEY (project_id) REFERENCES projects(id) ON DELETE CASCADE
);
```

```rust
use std::path::{Path, PathBuf};
use std::sync::Arc;
use tokio::sync::RwLock;

/// 项目元数据（轻量级，用于快速查询）
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ProjectMetadata {
    pub id: i64,
    pub name: String,
    pub root_path: String,
    pub config_file_path: String,
    pub language: Option<String>,
    pub extensions: Vec<String>,
    pub exclude_dirs: Vec<String>,
    pub respect_gitignore: bool,
    pub ignore_patterns: Vec<String>,
    pub last_indexed: Option<String>,
    pub created_at: String,
    pub updated_at: String,
}

/// 项目配置包装器（包含元数据和完整配置）
#[derive(Debug, Clone)]
pub struct ProjectEntry {
    pub metadata: ProjectMetadata,
    pub config: AppConfig,
    pub loaded_at: std::time::Instant,
    pub version: u64, // 用于检测配置变更
}

/// 项目注册表
pub struct ProjectRegistry {
    /// 内存缓存：project_id -> ProjectEntry
    cache: RwLock<HashMap<i64, Arc<ProjectEntry>>>,
    
    /// SQLite客户端（用于元数据持久化）
    sqlite_client: Arc<SqliteClient>,
    
    /// 全局配置模板（用于新项目默认值）
    global_template: AppConfig,
}
```

### 4.2 核心方法实现

#### 4.2.1 获取或加载配置（带缓存）

```rust
impl ProjectRegistry {
    pub async fn get_or_load(&self, project_id: i64) 
        -> Result<Arc<ProjectEntry>, RegistryError> 
    {
        // 1. 尝试从缓存读取
        {
            let cache = self.cache.read().await;
            if let Some(entry) = cache.get(&project_id) {
                tracing::debug!(project_id, "Cache hit");
                return Ok(entry.clone());
            }
        }
        
        // 2. 缓存未命中，从数据库和文件系统加载
        tracing::info!(project_id, "Cache miss, loading from storage");
        let entry = self.load_from_storage(project_id).await?;
        
        // 3. 写入缓存
        {
            let mut cache = self.cache.write().await;
            cache.insert(project_id, entry.clone());
        }
        
        Ok(entry)
    }
    
    async fn load_from_storage(&self, project_id: i64) 
        -> Result<Arc<ProjectEntry>, RegistryError> 
    {
        // 1. 从SQLite读取元数据
        let metadata = self.sqlite_client.with_transaction(|tx| {
            ProjectRepository::get_by_id(tx, project_id)
        })?.ok_or(RegistryError::ProjectNotFound(project_id))?;
        
        // 2. 构建配置文件路径
        let config_path = Path::new(&metadata.root_path)
            .join(&metadata.config_file_path);
        
        // 3. 加载项目配置文件（JSON格式）
        let config = if config_path.exists() {
            let content = std::fs::read_to_string(&config_path)
                .map_err(|e| RegistryError::Io(e))?;
            serde_json::from_str(&content)
                .map_err(|e| RegistryError::Deserialization(e.to_string()))?
        } else {
            // 配置文件不存在，使用全局模板
            tracing::warn!(
                project_id, 
                config_path = ?config_path,
                "Config file not found, using global template"
            );
            self.global_template.clone()
        };
        
        // 4. 创建ProjectEntry
        let entry = Arc::new(ProjectEntry {
            metadata,
            config,
            loaded_at: std::time::Instant::now(),
            version: 1,
        });
        
        Ok(entry)
    }
}
```

#### 4.2.2 创建新项目

```rust
impl ProjectRegistry {
    pub async fn create_project(
        &self,
        name: String,
        root_path: PathBuf,
        custom_config: Option<AppConfig>,
    ) -> Result<i64, RegistryError> {
        // 1. 验证路径
        if !root_path.exists() {
            return Err(RegistryError::PathNotFound(root_path));
        }
        
        // 2. 检查是否已存在
        if self.exists_by_path(&root_path).await? {
            return Err(RegistryError::DuplicatePath(root_path));
        }
        
        // 3. 创建配置文件目录
        let cce_dir = root_path.join(".cce");
        std::fs::create_dir_all(&cce_dir)
            .map_err(|e| RegistryError::Io(e))?;
        
        // 4. 生成配置文件
        let config_path = cce_dir.join("config.json");
        let config = custom_config.unwrap_or_else(|| {
            self.global_template.clone()
        });
        
        // 5. 写入配置文件（JSON格式）
        let config_json = serde_json::to_string_pretty(&config)
            .map_err(|e| RegistryError::Serialization(e.to_string()))?;
        std::fs::write(&config_path, config_json)
            .map_err(|e| RegistryError::Io(e))?;
        
        // 6. 准备元数据
        let now = chrono::Utc::now().to_rfc3339();
        let metadata = NewProjectRecord {
            name: name.clone(),
            root_path: root_path.to_string_lossy().to_string(),
            config_file_path: ".cce/config.json".to_string(),
            language: None,
            extensions: None,
            exclude_dirs: None,
            respect_gitignore: Some(true),
            ignore_patterns: None,
        };
        
        // 7. 插入数据库
        let id = self.sqlite_client.with_write_transaction(|tx| {
            ProjectRepository::insert(tx, &metadata)
        })?;
        
        // 8. 创建缓存条目
        let project_metadata = ProjectMetadata {
            id,
            name,
            root_path: root_path.to_string_lossy().to_string(),
            config_file_path: ".cce/config.json".to_string(),
            language: None,
            extensions: vec![],
            exclude_dirs: vec![],
            respect_gitignore: true,
            ignore_patterns: vec![],
            last_indexed: None,
            created_at: now.clone(),
            updated_at: now,
        };
        
        let entry = Arc::new(ProjectEntry {
            metadata: project_metadata,
            config,
            loaded_at: std::time::Instant::now(),
            version: 1,
        });
        
        // 9. 写入缓存
        {
            let mut cache = self.cache.write().await;
            cache.insert(id, entry);
        }
        
        tracing::info!(project_id = id, name, "Project created");
        Ok(id)
    }
}
```

#### 4.2.3 更新配置（热更新）

```rust
impl ProjectRegistry {
    pub async fn update_config(
        &self,
        project_id: i64,
        new_config: AppConfig,
    ) -> Result<(), RegistryError> {
        // 1. 验证配置
        new_config.validate()
            .map_err(RegistryError::Validation)?;
        
        // 2. 获取项目元数据
        let metadata = self.sqlite_client.with_transaction(|tx| {
            ProjectRepository::get_by_id(tx, project_id)
        })?.ok_or(RegistryError::ProjectNotFound(project_id))?;
        
        // 3. 写入配置文件（JSON格式）
        let config_path = Path::new(&metadata.root_path)
            .join(&metadata.config_file_path);
        
        let config_json = serde_json::to_string_pretty(&new_config)
            .map_err(|e| RegistryError::Serialization(e.to_string()))?;
        
        // 原子写入：先写临时文件，再重命名
        let temp_path = config_path.with_extension("tmp");
        std::fs::write(&temp_path, &config_json)
            .map_err(|e| RegistryError::Io(e))?;
        std::fs::rename(&temp_path, &config_path)
            .map_err(|e| RegistryError::Io(e))?;
        
        // 4. 更新数据库中的updated_at
        let now = chrono::Utc::now().to_rfc3339();
        self.sqlite_client.with_write_transaction(|tx| {
            let updates = ProjectUpdateRecord::default()
                .with_updated_at(now);
            ProjectRepository::update(tx, project_id, &updates)
        })?;
        
        // 5. 更新缓存（触发热更新）
        {
            let mut cache = self.cache.write().await;
            if let Some(entry) = cache.get_mut(&project_id) {
                let mut entry = Arc::make_mut(entry);
                entry.config = new_config;
                entry.version += 1;
                entry.loaded_at = std::time::Instant::now();
                
                tracing::info!(
                    project_id, 
                    version = entry.version,
                    "Project config updated (hot reload)"
                );
            }
        }
        
        // 6. 通知相关组件重新初始化（可选）
        // 例如：重新创建Qdrant collection、重建BM25索引等
        
        Ok(())
    }
}
```

```rust
impl ProjectRegistry {
    pub async fn reload_config(&self, project_id: i64) 
        -> Result<(), RegistryError> 
    {
        // 1. 从文件系统重新读取配置
        let metadata = self.sqlite_client.with_transaction(|tx| {
            ProjectRepository::get_by_id(tx, project_id)
        })?.ok_or(RegistryError::ProjectNotFound(project_id))?;
        
        let config_path = Path::new(&metadata.root_path)
            .join(&metadata.config_file_path);
        
        let new_config = if config_path.exists() {
            // 从JSON文件加载配置
            let content = std::fs::read_to_string(&config_path)
                .map_err(|e| RegistryError::Io(e))?;
            serde_json::from_str(&content)
                .map_err(|e| RegistryError::Deserialization(e.to_string()))?
        } else {
            self.global_template.clone()
        };
        
        // 2. 更新缓存
        {
            let mut cache = self.cache.write().await;
            if let Some(entry) = cache.get_mut(&project_id) {
                let mut entry = Arc::make_mut(entry);
                entry.config = new_config;
                entry.version += 1;
                entry.loaded_at = std::time::Instant::now();
                
                tracing::info!(
                    project_id,
                    version = entry.version,
                    "Project config reloaded from file"
                );
            }
        }
        
        Ok(())
    }
}
```

## 5. Engine集成

### 5.1 修改Engine结构

```rust
// src/engine.rs

pub struct CodeContextEngine {
    // 移除config字段
    qdrant: Arc<QdrantClient>,
    bm25: Arc<Mutex<Bm25Client>>,
    embedder: Arc<OpenAICompatibleProvider>,
    index_orchestrator: Arc<Mutex<IndexOrchestrator>>,
    searcher: Arc<Mutex<Searcher>>,
    
    // 添加项目注册表
    project_registry: Arc<ProjectRegistry>,
}

impl CodeContextEngine {
    /// 初始化Engine（不加载任何项目配置）
    pub fn new(global_config: AppConfig) -> Result<Self, EngineError> {
        let sqlite_client = Arc::new(SqliteClient::new(&global_config.database.sqlite)?);
        
        let project_registry = Arc::new(ProjectRegistry::new(
            sqlite_client.clone(),
            global_config.clone(),
        )?);
        
        let qdrant = Arc::new(QdrantClient::new(global_config.database.qdrant)?);
        let bm25 = Arc::new(Mutex::new(Bm25Client::new(global_config.database.bm25)));
        let embedder = Arc::new(OpenAICompatibleProvider::new(global_config.embedder)?);
        
        let index_orchestrator = Arc::new(Mutex::new(
            IndexOrchestrator::new()
                .with_qdrant(qdrant.clone())
                .with_bm25(bm25.clone())
                .with_embedder(embedder.clone())
        ));
        
        let searcher = Arc::new(Mutex::new(Searcher::new(
            qdrant.clone(),
            embedder.clone(),
            bm25.clone(),
        )));
        
        Ok(Self {
            qdrant,
            bm25,
            embedder,
            index_orchestrator,
            searcher,
            project_registry,
        })
    }
    
    /// 搜索（动态加载项目配置）
    pub async fn search(
        &self,
        project_id: i64,
        options: &QueryOptions,
    ) -> Result<QueryResult, EngineError> {
        // 1. 获取项目配置（带缓存）
        let project_entry = self.project_registry.get_or_load(project_id).await?;
        let config = &project_entry.config;
        
        // 2. 应用项目特定的配置（如需要）
        // 例如：调整搜索参数、启用/禁用某些功能
        
        // 3. 执行搜索
        let searcher = self.searcher.lock().await;
        searcher.search(options).await.map_err(EngineError::Query)
    }
    
    /// 索引（动态加载项目配置）
    pub async fn index(
        &self,
        project_id: i64,
        options: IndexOptions,
    ) -> Result<IndexResult, EngineError> {
        // 1. 获取项目配置
        let project_entry = self.project_registry.get_or_load(project_id).await?;
        let config = &project_entry.config;
        
        // 2. 根据配置调整索引行为
        let mut orchestrator = self.index_orchestrator.lock().await;
        
        // 例如：应用项目特定的扫描规则
        if let Some(scanner_config) = &config.scanner {
            orchestrator.apply_scanner_config(scanner_config);
        }
        
        // 3. 执行索引
        orchestrator.execute(options).await.map_err(EngineError::Index)
    }
    
    /// 获取项目注册表（用于API层）
    pub fn project_registry(&self) -> &Arc<ProjectRegistry> {
        &self.project_registry
    }
}
```

```rust
    })
```

## 7. 缓存策略

### 7.1 缓存生命周期

| 操作 | 缓存行为 | 说明 |
|------|----------|------|
| 首次访问 | 加载并缓存 | 从文件系统和数据库加载 |
| 后续访问 | 直接读取缓存 | O(1)时间复杂度 |
| 配置更新 | 更新缓存 | 立即生效，版本号+1 |
| 配置重载 | 刷新缓存 | 从文件重新读取 |
| 项目删除 | 移除缓存 | 释放内存 |

### 7.2 缓存清理策略

```rust
impl ProjectRegistry {
    /// 定期清理长时间未使用的缓存
    pub async fn cleanup_idle_cache(&self, idle_threshold: Duration) {
        let now = std::time::Instant::now();
        let mut cache = self.cache.write().await;
        
        let before = cache.len();
        cache.retain(|_, entry| {
            now.duration_since(entry.loaded_at) < idle_threshold
        });
        let after = cache.len();
        
        if before != after {
            tracing::info!(
                cleaned = before - after,
                remaining = after,
                "Cleaned up idle cache entries"
            );
        }
    }
}

// 在后台任务中定期执行
tokio::spawn(async move {
    let interval = Duration::from_secs(3600); // 每小时
    loop {
        tokio::time::sleep(interval).await;
        registry.cleanup_idle_cache(Duration::from_secs(86400)).await;
    }
});
```

## 8. 并发控制

### 8.1 读写锁策略

- **读操作**：使用 `RwLock::read()`，允许多个读者并发
- **写操作**：使用 `RwLock::write()`，独占访问
- **粒度**：整个cache使用一个RwLock，简化实现

### 8.2 事务一致性

```rust
// 更新配置的原子性保证
pub async fn update_config(&self, project_id: i64, new_config: AppConfig) 
    -> Result<(), RegistryError> 
{
    // 1. 先写文件系统（原子操作：临时文件 + rename）
    write_config_file_atomic(&config_path, &new_config)?;
    
    // 2. 再更新数据库（事务）
    self.sqlite_client.with_write_transaction(|tx| {
        ProjectRepository::update_updated_at(tx, project_id, &now)
    })?;
    
    // 3. 最后更新缓存（内存操作，不会失败）
    update_cache(project_id, new_config);
    
    Ok(())
}
```

**注意顺序**：文件系统 → 数据库 → 缓存
- 如果文件系统失败：回滚，不影响其他
- 如果数据库失败：文件系统已提交，可以重试
- 缓存更新永远不会失败

## 9. 错误处理

### 9.1 RegistryError定义

```rust
#[derive(Debug, thiserror::Error)]
pub enum RegistryError {
    #[error("Project not found: {0}")]
    ProjectNotFound(i64),
    
    #[error("Path not found: {0}")]
    PathNotFound(PathBuf),
    
    #[error("Duplicate path: {0}")]
    DuplicatePath(PathBuf),
    
    #[error("Configuration validation failed: {0}")]
    Validation(String),
    
    #[error("IO error: {0}")]
    Io(#[from] std::io::Error),
    
    #[error("Serialization error: {0}")]
    Serialization(String),
    
    #[error("Deserialization error: {0}")]
    Deserialization(String),
    
    #[error("Database error: {0}")]
    Database(#[from] StorageError),
    
    #[error("Config load error: {0}")]
    ConfigLoad(#[from] ConfigError),
}
```

### 9.2 错误恢复策略

| 错误类型 | 恢复策略 |
|----------|----------|
| ProjectNotFound | 返回404，提示用户创建项目 |
| PathNotFound | 返回400，要求用户提供有效路径 |
| DuplicatePath | 返回409，提示项目已存在 |
| Validation | 返回400，显示具体验证错误 |
| Io | 记录日志，返回500，可重试 |
| Serialization | 记录日志，返回500，检查配置文件格式 |
| Database | 记录日志，返回500，检查数据库连接 |

## 13. 总结

### 核心优势

1. **真正的多项目支持** - 每个项目有独立配置
2. **热更新能力** - 配置变更立即生效，无需重启
3. **高性能缓存** - 首次加载后O(1)访问
4. **易于调试** - TOML配置文件人类可读
5. **简洁的架构** - 无复杂的二进制序列化

### 关键设计决策

1. **配置文件独立存储** - 而非SQLite BLOB
2. **移除变更历史** - 简化设计，降低复杂度
3. **懒加载策略** - 避免启动时加载所有项目
4. **原子写入** - 临时文件 + rename保证一致性
