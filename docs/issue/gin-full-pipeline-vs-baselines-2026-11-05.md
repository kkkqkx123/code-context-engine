# Gin 全管线相对基线差距分析（2026-11-05）

日期：2026-11-05
范围：Go Gin  fixture，三基线对照（全管线、直接切分、全管线原文）
结论：全管线在干净变体下领先，在含干扰变体与原文对照下系统性落后，根因为碎片更多加文本稀释，非评测噪声

## 1. 三基线含义与对照逻辑

直接切分保留实体分组但文本为原文切片，用于衡量分组本身价值。全管线在同样分组上把文本改写为自然语言，用于衡量改写价值。全管线原文与全管线共享完全相同的分组与区间，仅把文本替换回原文切片，用于分离分组边界效应与改写文本效应。三种基线块数上全管线与原文完全一致，向量一千一百余块，词项九百余块，直接切分向量约六百八十块，词项约五百三十块。全管线比直接切分多约六到七成块，块数膨胀本身即构成小切口劣势。

全管线与原文区间完全相同，两者指标差即纯文本差距，与切分无关。全管线与直接切分区间不同，两者指标差为分组加文本综合效应。干净变体下全管线领先直接切分，证明分组加改写本身有益。含干扰变体与原文对照下落后，证明碎片与改写在干扰下被放大。

评测口径要求目标行全覆盖，碎片越多所需共现块越多。直接切分以大块取胜并非语义更准，而是在该口径下占优。不通过放宽口径掩盖碎片，只减少不必要碎片并提升文本纯度。

## 2. 聚合差距总览

小切口下全管线词项落后原文约零点零四，分组词项落后约零点零四。向量单路全管线反而领先原文约零点零四，但向量分组路落后原文约零点零七。词项路原文持续优于自然语言，向量分组路原文持续优于自然语言，证明改写文本在需要精确匹配与组覆盖的场景下丢失信号。

按查询类型看，模糊与语义查询为重灾区。含干扰变体下模糊词项全管线低于直接切分约零点一三，分组模糊词项低约零点一三，语义向量分组路全管线低于原文。限定查询全管线与原文持平，说明符号精确匹配场景改写尚可，意图概括场景改写丢失关键宾语。

大切口上差距收敛但相关层持续偏低，说明碎片需要更大窗口才能补回，而辅助小区间即使大切口也难恢复。分组检索器通过段合并补回主目标，但补不回辅助小区间。

## 3. 逐查询证据

切分型退化指全管线与原文同败于直接切分，目标多为大区间。分发主干约七十行在全管线词项路被截成两块，尾块在条件分支处硬截断，直接切分单块覆盖。路由树查找约二百五十行与路由插入约一百一十四行在全管线需三块以上联合覆盖，直接切分单块覆盖。上述查询在多切口下稳定复现，与窗口无关，为结构性碎片。

文本型退化指全管线败于原文而原文持平或优于直接切分，目标多为短小方法。格式化字符串方法仅三行，向量路直接与全管线皆零而原文完全召回，分组向量亦然，跨切口稳定复现。响应写入方法、上下文 JSON 方法、路由组中间件方法亦有原文独胜切口。查询动词与块内多个方法共享，查询向量落入块中心而非目标，原文保留完整调用序列反而更贴近查询。

标题误标为独立证据。渲染方法目标行在词项转储中位于以 Cookie 为标题的块内，块标题为上下文 Cookie 而非渲染，关键词亦以 Cookie 为主。限定查询依赖标题共现，误标直接导致零召回。原文基线共享同样标题但内容为完整源码，内容中的真实签名救回排名，反证误标责任在改写而非边界。

向量稀释为独立证据。字符串方法块内含字符串、重定向、数据等多方法，目标文本仅占块约三分之一，查询中的格式化一词在块内无对应，原文中的 format 参数名反而命中。响应写入方法块内含十余方法，查询中的头部与字节宾语被邻居淹没。

## 4. 块输出与源码对照事实

引擎结构体组横跨约六百行，词项切出二十余块。请求分发主干在向量路独占一块尚可，在词项路被截为两块。树节点组中路由插入方法被切成三块。上下文组中渲染方法与其前后方法同块，标题却为邻居方法。 JSON 簇八个独立方法压入同一合并组，字符串簇八个独立方法压入同一合并组，响应写入组多方法压入同一结构体组。合并后目标仅占块文本六分之一到三分之一。

部分块声明区间远大于文本实际承载。引擎组某向量块声明覆盖约六百行而文本仅三百余词，实为摘要而非覆盖。区间按声明判定覆盖，检索按文本排序，两者脱节导致声称可覆盖的块排不上，排得上的块又需多块拼凑。原文按同样区间拿到完整源码，文本与区间一致，因而在同边界下反而胜出。

## 5. 根因分析

碎片预算与大组失配为首因。统一词数预算对大结构体组过小，组文本远超预算只能连环切散。组头概览本身消耗预算，成员被迫外溢，直接切分头极小因而同组可装更多成员，全管线头大因而同组成员被切更散。评估要求全覆盖，碎片在小切口天然不利。

小碎片合并阈值过宽为次因。五十行跨度内短方法无差别合并，把高价值短目标与邻居捆绑。合并本意减少碎片，却把检索目标变成块内少数派。合并标题取首成员或组名，与块内多数方法名不一致，标题信号失真。

自然语言模板保真不足为第三因。词项模板归一化丢失精确形态，大小写与词缀信号被抹平，短签名区分度下降。向量模板概括丢失调用细节，长代码中的动宾搭配与错误码、内容类型等关键宾语被压缩。测试文件同名小写调用因短而集中，反而在词袋下占优。

测试干扰为放大器而非根因。干净变体下全管线领先，证明语义本身有益。干扰块占比过半，碎片越多在测试同名调用面前越易被超越。不引入测试降权掩盖逻辑，只在文本侧增强实现块区分度。
