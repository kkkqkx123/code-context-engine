# 元数据双后端差异（归档：合理部分）

> 对比对象：本地嵌入式数据库分支与远端数据库服务分支。
> 两者实现同一份元数据合约：工程目录、世代清单、世代覆盖、内容索引、进度检查点、关系快照、准入审计、容量统计。

## 数据布局

- 本地为每个工程维护独立数据库文件及预写日志附属文件，删除工程走句柄逐出加文件删除。
- 远端为共享库内按工程字段过滤，删除工程走单事务内的多表行删除。
- 工程进入语义因此不同：本地打开工程数据库文件，远端只是克隆连接池句柄。差异贴合物理形态。

## 事务与连接

- 本地每操作开启一次事务，读写分离为写连接与可选读连接。
- 远端每操作从连接池取连接并在其上执行单事务。
- 合约要求每个命名操作自身原子、可按唯一键幂等重放、瞬时失败可重试，两者都满足。

## 快照编码

- 本地快照体使用压缩的规范二进制编码并维护增量链。
- 远端快照体使用二进制大字段承载，增量链语义与合约一致。
- 快照分配、发布、就绪、激活、失败标记、按区间读增量链、基线查找的语义一致。

## 韧性与观测

- 远端自带连接池、断路器与数据库错误分类，只有瞬时类错误计入断路。
- 本地为进程内调用，无断路器，自带进程内指标与缓存，不经过网络。
- 容量统计口径不同但含义一致：本地汇总主库加各工程文件，远端统计整库加工程估算。

## 模式管理

- 本地使用版本化的数据定义迁移，远端使用版本表加一次性建表语句。
- 构建时两者都不需要真实数据库：本地是文件数据库，远端全部使用运行时拼接的 plain 语句执行。
