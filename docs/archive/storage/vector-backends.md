# 向量双后端差异（归档：合理部分）

> 对比对象：本地嵌入式引擎分支与远端服务分支。
> 两者实现同一份向量合约，写入、检索、按文件与分组删除、计数、集合管理等语义一致。

## 过滤语义

- 共享语义锚点是中立 crate 中的载荷谓词，文档声明后端下推只是优化，必须与该谓词一致。
- 本地分支拒绝携带原生过滤透传字段的查询，远端分支将其作为透传使用。该字段定位为远端调试逃生口，不允许出现在业务查询路径，属于合理的显式不对称。
- 本地对目录前缀与世代排除做超取加后过滤，远端全部下推。性能形态不同，可见结果一致。

## 韧性与运维面

- 远端分支自带断路器、重试、指标、诊断探针、可选的服务端进程托管、容量预估与配置升级调度，属于跨进程调用的必要成本。
- 本地分支为进程内调用，无断路器与重试，维度与非有限数值做快速失败校验，阻塞操作放到后台线程池执行。
- 装配层的断路器摘要与托管进程标识在本地分支返回固定标记，属于合理差异。

## 集合与索引调优

- 本地在打开时建集合并校验维度，维度不一致直接要求重建；索引调优参数为可选子集。
- 远端按数据量提供多档集合预设，另有量化、预写日志与向量存留等服务端特有调优项。
- 集合共享名称与维度必须匹配嵌入模型输出的约束对两者相同。

## 批量与计数实现

- 远端提供原生的多文件批量删除，本地走合约默认的逐个删除循环，可见结果相同。
- 本地按分组计数走分页扫描载荷统计，远端走服务端计数。本地形态在大集合下更慢，但语义一致。

## 健康语义

- 本地健康表示集合存在且引擎可打开，属于存活探针。
- 远端健康表示服务端可达，属于连通探针。
- 合约明确健康只表达存活，不表达数据完整性，两者都符合该约定。
