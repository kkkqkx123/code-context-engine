# P1 基准实测基线归档

本文归档 P1 优化工作前采集的四组基准实测数据。绝对数值来自合成负载，仅相对加速比为有效信号。

## 采集环境

- 沙箱单机多核，`cargo build --benches` 全部通过，`cargo run --release --bench` 执行。
- criterion 采样 10 次，`measurement_time` 十秒级，大规模用例因采样不足有外推告警。
- T-4 使用内存 SQLite，T-5 使用本地 tantivy 临时目录，其余为内存构造。
- T-5 完整两万文档规模超出沙箱能力，实际按两千文档缩减规模采集，criterion 段因预估耗时过长未能完成，仅人工计时段可用。

## 基线结论

写路径的真正可优化点是事务合并而非语句预编译。全文提交频率是数量级放大源。关系终结与快照的全量路径随规模线性增长，热更新增量已是在线路径；按影响集拷贝原语无生产调用方，其基准数值为原语表征。
