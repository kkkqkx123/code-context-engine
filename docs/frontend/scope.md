# 前端职责边界

## 概述

`frontend/` 是面向人类用户的操作界面，覆盖项目注册、索引管理、混合搜索、代码图浏览、实体与调用关系、健康检查、指标、配置与日志等能力。它消费后端的常规查询与管理 API。

## 不提供的能力：Wiki / WCP

前端**不提供** Wiki 相关功能，也不消费 Wiki Context Package（WCP）。原因如下：

- WCP 是面向下游 RepoWiki 生成器的机器契约（文件清单、实体目录、依赖图、指标、聚类、阅读路径、Mermaid 骨架），由确定性静态分析产出，不是给人浏览的界面数据。
- WCP 导出的唯一公开入口是 CLI 子命令 `cce wiki context` 与 `cce wiki diff`；HTTP 端点仅作为 CLI 的内部传输通道。
- MCP 侧的只读画像用于 AI agent 生成文档时的有限步回查，同样不经过前端。

因此 `frontend/src` 中不存在 wiki 路由、API 客户端、store 或 schema 字段，这是职责划分的结果，而非待补功能。若未来需要面向人的文档浏览界面，应作为独立产品课题评估，不复用 WCP 的机器契约。
