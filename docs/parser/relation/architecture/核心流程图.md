## 3. 调用链查询流程图

```
┌─────────────────────────────────────────────────────────────────┐
│                  调用链查询流程（正向）                           │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │     输入：start_entity_id, max_depth  │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │  Step 1: 验证起始节点存在             │
        │  index.contains_function(start_id)   │
        └───────────────────────────────────────┘
                    │               │
                存在            不存在
                    │               │
                    ▼               ▼
                继续          返回错误
                    │
                    ▼
        ┌───────────────────────────────────────┐
        │  Step 2: 初始化遍历                   │
        │  - visited = {}                       │
        │  - queue = [(start_id, depth=0)]      │
        │  - result = []                        │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │  Step 3: BFS 遍历                     │
        │  while queue not empty:               │
        │    (current, depth) = queue.pop()     │
        │                                      │
        │    if depth > max_depth: continue    │
        │    if current in visited: continue   │
        │    visited.add(current)              │
        │                                      │
        │    # 获取被调用者                    │
        │    relations = index.                │
        │       get_resolved_relations(current)│
        │    for rel in relations:             │
        │      if rel.callee_id:               │
        │        queue.push(                   │
        │          (rel.callee_id, depth+1)    │
        │        )                             │
        │                                      │
        │    result.add(CallChainNode{...})    │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │     输出：Vec<CallChainNode>          │
        │  [node0, node1, node2, ...]           │
        │  (按深度排序)                          │
        └───────────────────────────────────────┘
```

```
┌─────────────────────────────────────────────────────────────────┐
│                  调用链查询流程（反向）                           │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │     输入：target_entity_id, max_depth │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │  Step 1: 验证目标节点存在             │
        │  index.get_function(target_id)       │
        └───────────────────────────────────────┘
                    │               │
                存在            不存在
                    │               │
                    ▼               ▼
                继续          返回错误
                    │
                    ▼
        ┌───────────────────────────────────────┐
        │  Step 2: 初始化遍历                   │
        │  - visited = {}                       │
        │  - queue = []                         │
        │  - callers = index.get_callers(target)│
        │  - for caller in callers:             │
        │      queue.push((caller, depth=1))    │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │  Step 3: BFS 遍历（反向）             │
        │  while queue not empty:               │
        │    (current, depth) = queue.pop()     │
        │                                      │
        │    if depth > max_depth: continue    │
        │    if current in visited: continue   │
        │    visited.add(current)              │
        │                                      │
        │    # 获取调用者（反向）              │
        │    callers = index.get_callers(current)│
        │    for caller in callers:            │
        │      queue.push(                     │
        │        (caller, depth+1)             │
        │      )                               │
        │                                      │
        │    result.add(CallChainNode{...})    │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │     输出：Vec<CallChainNode>          │
        │  [caller1, caller2, ...]              │
        │  (谁调用了 target)                     │
        └───────────────────────────────────────┘
```

## 4. 热更新流程图

```
┌─────────────────────────────────────────────────────────────────┐
│                      热更新流程                                   │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │     输入：修改的文件列表              │
        │         [file_a, file_b, ...]         │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │  Step 1: 收集受影响的文件             │
        │                                      │
        │  affected_files = set()              │
        │  for file in modified_files:         │
        │    # 添加修改的文件本身               │
        │    affected_files.add(file)          │
        │    # 添加依赖该文件的所有文件        │
        │    dependents = dep_graph.           │
        │       collect_transitive_dependents( │
        │         file, max_depth=0            │
        │       )                              │
        │    affected_files.update(dependents) │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │  Step 2: 拓扑排序                     │
        │                                      │
        │  try:                                 │
        │    sorted_files = dep_graph.         │
        │       topological_sort(affected)      │
        │  except CycleDetected:               │
        │    # 回退策略：按路径字母排序         │
        │    sorted_files = sorted(affected)   │
        │    log_warning("Cycle detected")     │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │  Step 3: 按顺序重新解析               │
        │                                      │
        │  for file_path in sorted_files:      │
        │    # 1. 重新解析文件                 │
        │    parsed = parse_file(file_path)    │
        │                                      │
        │    # 2. 重新提取符号                 │
        │    local_table = LocalSymbolTable    │
        │       ::from_parsed_file(parsed)     │
        │                                      │
        │    # 3. 重新解析关系                 │
        │    resolver = RelationResolver(...)  │
        │    relations = resolver.resolve_batch│
        │       (parsed.raw_relations, ...)    │
        │                                      │
        │    # 4. 更新索引                     │
        │    index.remove_file(file_path)      │
        │    index.add_function(...)           │
        │    index.add_resolved_relations(...) │
        │                                      │
        │    # 5. 更新依赖图                   │
        │    dep_graph.remove_file(file_path)  │
        │    for dep in parsed.imports:        │
        │      dep_graph.add_dependency(       │
        │        file_path, dep.resolved       │
        │      )                               │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │     输出：更新后的 RelationIndex      │
        └───────────────────────────────────────┘
```

## 6. 可见性检查流程图

```
┌─────────────────────────────────────────────────────────────────┐
│                    可见性检查流程                                 │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │     输入：visibility, from_scope,    │
        │          defined_in, language        │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │  Step 1: 根据语言选择规则             │
        │                                      │
        │  match language:                     │
        │    Rust -> is_visible_rust           │
        │    Java -> is_visible_java           │
        │    C# -> is_visible_csharp           │
        │    C++ -> is_visible_cpp             │
        │    Python -> is_visible_python       │
        │    JS/TS -> is_visible_javascript    │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │  Step 2: 应用可见性规则（以 Rust 为例）│
        │                                      │
        │  match visibility:                   │
        │    Public -> true                    │
        │                                      │
        │    Package ->                        │
        │      from.package == defined.package │
        │                                      │
        │    Module ->                         │
        │      from.module_path.starts_with(   │
        │        defined.module_path           │
        │      )                               │
        │                                      │
        │    Super ->                          │
        │      from 是 defined 的父模块        │
        │                                      │
        │    Restricted { path } ->            │
        │      from.module_path.starts_with(   │
        │        path                          │
        │      )                               │
        │                                      │
        │    Private ->                        │
        │      from.file == defined.file       │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │  Step 3: 特殊处理（如 protected）     │
        │                                      │
        │  if visibility == Protected:         │
        │    # 需要检查继承关系                │
        │    is_subclass = inheritance_graph.  │
        │       is_subclass_of(from_type,      │
        │                      defined_type)   │
        │    same_package = from.package ==    │
        │                    defined.package   │
        │    return is_subclass || same_pkg    │
        └───────────────────────────────────────┘
                              │
                              ▼
        ┌───────────────────────────────────────┐
        │     输出：bool                        │
        │  true = 可见                         │
        │  false = 不可见                      │
        └───────────────────────────────────────┘
```

## 总结

这些流程图展示了 Relation 模块的核心工作流程：

1. **索引构建** - 从 ParsedFile 到 RelationIndex 的完整流水线
2. **符号解析** - 多阶段解析策略，从限定名到外部调用分类
3. **调用链查询** - 正向和反向的 BFS 遍历
4. **热更新** - 依赖传播和增量更新
5. **外部调用分类** - 标准库、外部包、未知的分类逻辑
6. **可见性检查** - 多语言的可见性规则应用

所有流程都遵循分层设计，各阶段职责清晰，便于理解和维护。
