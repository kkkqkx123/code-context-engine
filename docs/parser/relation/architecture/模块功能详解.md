# Relation 模块功能详解

## 1. Config Parser 模块

### 功能概述
解析各种构建系统的配置文件，提取项目依赖信息，用于导入分类。

### 核心文件

#### `mod.rs`
模块入口，重新导出公共类型。

#### `types.rs`
定义核心类型：
```rust
pub enum PackageType {
    External,   // 外部依赖
    Dev,        // 开发依赖
    Local,      // 本地依赖
}

pub struct Dependency {
    pub name: String,
    pub package_type: PackageType,
}
```

#### `detector.rs`
构建配置检测器：
- `BuildConfigParser` - 主检测器类
- 扫描项目目录，自动检测构建系统
- 提取包名列表

#### `parsers/`
各语言解析器实现：
- `cargo.rs` - Rust Cargo.toml
- `javascript/{npm.rs, pnpm.rs, yarn.rs}` - JS 包管理器
- `python/{pip.rs, poetry.rs, pipenv.rs, ...}` - Python 包管理
- `java/{maven.rs, gradle.rs}` - Java 构建工具
- `cpp/{cmake.rs, make.rs}` - C/C++ 构建
- `go.rs` - Go modules
- `dotnet.rs` - .NET csproj
- `php.rs` - Composer
- `ruby.rs` - Gemfile

### 使用流程
```
1. 创建 BuildConfigParser
2. 调用 scan_project(root_dir)
3. 自动检测并解析所有构建配置文件
4. 通过 dependencies_for_language(lang) 获取依赖列表
```

### 简化设计
新架构已简化为仅提取包名，移除了版本、来源、特性等冗余元数据。

## 2. Extraction 模块

### 功能概述
语言无关的符号提取层，提供统一的导入/导出提取接口。

### 核心文件

#### `traits.rs`
定义核心提取器 trait：
```rust
pub trait SymbolExtractor: Send + Sync {
    fn extract_imports(&self, tree: &Tree, source: &str) -> Vec<StandardizedImport>;
    fn extract_exports(&self, tree: &Tree, source: &str) -> Vec<StandardizedExport>;
    fn language(&self) -> Language;
}

pub fn create_extractor(language: Language) -> Option<Box<dyn SymbolExtractor>>;
pub fn extract_from_file(tree, source, language) -> Option<(imports, exports)>;
```

#### `common/standardized.rs`
标准化类型定义：

**导入分类**：
```rust
pub enum ImportClass {
    StandardLibrary,
    ExternalPackage,
    InternalModule,
    Unknown,
}
```

**导入类型**：
```rust
pub enum ImportKind {
    SymbolImport,      // import { foo } from 'module'
    ModuleImport,      // import * as mod from 'module'
    SideEffectImport,  // import 'module'
    DynamicImport,     // import('module')
    Include,           // C/C++ include
    DefaultImport,
    NamespaceImport,
}
```

**导出类型**：
```rust
pub enum ExportKind {
    Named,     // export { foo }
    Default,   // export default foo
    Reexport,  // export { foo } from 'module'
    Wildcard,  // export * from 'module'
}
```

**标准化导入/导出**：
```rust
pub struct StandardizedImport {
    pub kind: ImportKind,
    pub source: String,
    pub target: ImportTarget,
    pub alias: Option<String>,
    pub is_wildcard: bool,
    pub is_default: bool,
    pub is_system_header: bool,
    pub is_relative: bool,
}

pub struct StandardizedExport {
    pub kind: ExportKind,
    pub target: ExportTarget,
    pub is_reexport: bool,
}
```

#### 语言特定提取器
`parser/extractor/{c.rs, cpp.rs, javascript.rs, ...}`
- 实现 `SymbolExtractor` trait
- 针对各语言语法特性提取导入/导出
- 使用 tree-sitter AST 进行解析

### 使用流程
```
1. 根据语言创建提取器 (create_extractor)
2. 调用 extract_imports(tree, source)
3. 调用 extract_exports(tree, source)
4. 获取标准化的导入/导出表
```

## 3. Symbol 模块

### 功能概述
符号抽象层，提供统一的符号标识、可见性、作用域和元数据类型。

### 核心文件

#### `id.rs`
符号标识符：
```rust
pub struct SymbolId(pub u64);

pub struct GlobalSymbolIdAllocator {
    counter: Arc<AtomicU64>,
}
```
- 全局原子递增分配器
- 线程安全
- 8 字节紧凑表示

#### `visibility.rs`
多语言可见性模型：
```rust
pub enum Visibility {
    Public,
    Package,        // 包级
    Module,         // 模块级
    Super,          // 父级
    Private,
    Restricted { path: String },
    Protected,
    Internal,
    ProtectedInternal,
    PrivateProtected,
    Friend { allowed: Vec<String> },
}

impl Visibility {
    pub fn is_visible_from(&self, from_scope, defined_in, language) -> bool;
    pub fn is_visible_from_with_inheritance(...); // 支持继承的 protected 检查
}
```

支持的语言规则：
- Rust: pub / pub(crate) / pub(super) / private
- Java: public / protected / package / private
- Go: 导出/未导出（基于命名）
- Python: public / _private / __dunder__
- C#: public / internal / protected / private / protected internal
- C++: public / protected / private / friend

#### `scope.rs`
作用域上下文：
```rust
pub struct ScopeContext {
    pub file_path: String,
    pub package: String,
    pub module_path: Option<String>,
    // ...
}
```

#### `metadata.rs`
符号元数据：
```rust
pub struct SymbolMetadata {
    pub name: String,
    pub kind: EntityKind,
    pub location: SymbolLocation,
    // ...
}

pub struct SymbolLocation {
    pub file_path: String,
    pub span: Span,
    pub language: Language,
}
```

#### `inheritance.rs`
继承图：
- 记录类的继承关系
- 支持接口实现
- 用于 protected 成员访问检查

## 4. Symbol Table 模块

### 功能概述
四层符号表层次结构，支持跨文件符号解析。

### 核心文件

#### `local.rs` - 文件级符号表
```rust
pub struct LocalSymbolTable {
    pub file_path: Arc<str>,
    pub language: Language,
    entities: Arc<HashMap<EntityId, Entity>>,
    name_index: HashMap<Arc<str>, Vec<EntityId>>,
    metadata_cache: HashMap<EntityId, SymbolMetadata>,
}
```

功能：
- 文件内符号索引
- 按名称查找
- 按类型查找
- 支持函数重载
- 使用 Arc 共享实体数据

#### `module.rs` - 模块级符号表
- 管理模块的导入/导出
- 支持导入别名
- 支持重导出
- 支持通配符导入

#### `package.rs` - 包级符号表
- 管理包的公共导出
- 包内符号解析
- 内部符号管理

#### `project.rs` - 项目级符号表
```rust
pub struct ProjectSymbolTable {
    root_path: PathBuf,
    packages: DashMap<String, PackageSymbolTable>,
    external_deps: DashMap<String, ExternalSymbolTable>,
    global_index: DashMap<String, SymbolId>,
    simple_name_index: DashMap<String, Vec<(package_id, module_path, SymbolId)>>,
}
```

功能：
- 管理所有包
- 管理外部依赖
- 全局符号索引
- 跨包符号解析
- 支持导入解析
- 支持重导出解析

#### `sfc.rs` - SFC 支持
单文件组件（Vue SFC）的跨块引用支持：
- 模板块引用
- 脚本块引用
- 样式块引用

### 解析流程
```
1. LocalSymbolTable 解析文件内符号
2. ModuleSymbolTable 解析模块导入/导出
3. PackageSymbolTable 解析包级导出
4. ProjectSymbolTable 解析跨包和外部依赖
```

## 6. Index 模块

### 功能概述
关系索引和解析，提供高效的调用关系存储和查询。

### 核心文件

#### `core.rs` - 核心索引结构
```rust
pub struct RelationIndex {
    function_index: DashMap<EntityId, Entity>,
    entity_file_index: DashMap<EntityId, String>,
    resolved_relation_index: DashMap<EntityId, Vec<ResolvedRelation>>,
    callee_index: DashMap<EntityId, Vec<EntityId>>, // 反向索引
    import_index: DashMap<String, ImportTable>,
    file_index: DashMap<String, FileInfo>,
    export_index: DashMap<String, Vec<ExportInfo>>,
    dependency_graph: Arc<FileDependencyGraph>,
}
```

#### `entity_index.rs` - 实体操作
- `add_function` / `get_function`
- `contains_function`
- `get_function_by_entity_id`

#### `relation_query.rs` - 查询操作
- `get_resolved_relations_by_caller`
- `get_callers_by_callee_entity`
- `get_callers_by_callee_and_type`
- 继承层次查询
- 前端组件查询

#### `file_index.rs` - 文件操作
- `add_import_table`
- `add_export_info`
- `get_file_path_by_entity`

#### `reverse_index.rs` - 反向索引
- 选择性索引
- 热度追踪
- 性能统计

#### `resolver.rs` - 关系解析器
```rust
pub struct RelationResolver {
    filter_stdlib_calls: bool,
    external_packages: Option<HashMap<Language, HashSet<String>>>,
    external_dependencies: Option<HashMap<Language, Vec<Dependency>>>,
    dependency_index: Option<DependencyIndex>,
}

impl RelationResolver {
    pub fn resolve(raw_data, parsed, symbol_table) -> Option<ResolvedRelation>;
    pub fn resolve_batch(raw_relations, parsed, symbol_table) -> Vec<ResolvedRelation>;
}
```

解析流程：
1. 检查是否是标准库调用（可选过滤）
2. 尝试完全限定名解析（file::callee_name）
3. 回退到简单名解析（simple:callee_name）
4. 回退到局部符号
5. 分类外部调用（stdlib/external/unknown）

#### `local_call_resolver.rs` - 本地调用解析器
```rust
pub struct LocalCallResolver {
    config: LocalCallResolverConfig,
}

impl LocalCallResolver {
    pub fn resolve(relations, entities) -> Vec<LocalCall>;
    pub fn resolve_from_parsed_file(parsed_file) -> Vec<LocalCall>;
}
```

功能：
- 解析文件内调用
- 计算调用顺序
- 支持函数签名匹配
- 跳过跨文件调用

#### `dependency_index.rs` - 依赖索引
- 高效的依赖查找
- 支持批量查询
- 性能统计

## 7. Query 模块

### 功能概述
高级调用链查询 API，提供用户友好的查询接口。

### 核心文件

#### `query.rs`
```rust
pub struct CallChainQuery {
    index: RelationIndex,
    metrics: Arc<GenericCollector>,
}

pub struct CallChainTraverser<'a> {
    index: &'a RelationIndex,
    config: TraversalConfig,
}

pub struct TraversalConfig {
    pub max_depth: usize,
    pub include_start_node: bool,
    pub stop_on_cycles: bool,
    pub direction: TraversalDirection,
    pub debug: bool,
    pub max_nodes: usize,
}
```

主要方法：
- `get_callees_by_entity(entity_id)` - 获取被调用者
- `get_callers_by_entity(entity_id)` - 获取调用者
- `query_forward_by_entity(entity_id, max_depth)` - 正向调用链
- `query_backward_by_entity(entity_id, max_depth)` - 反向调用链
- `find_call_chain(start_id, end_id, max_depth)` - 查找调用路径
- `get_base_classes(class_id)` - 获取基类
- `get_derived_classes(class_id)` - 获取派生类

特性：
- 循环安全遍历
- 可配置深度限制
- 指标收集
- 详细错误日志

## 8. Dependency Graph 模块

### 功能概述
文件级依赖图，用于热更新时的依赖传播。

### 核心文件

#### `dependency_graph.rs`
```rust
pub struct FileDependencyGraph {
    forward_edges: DashMap<String, Vec<String>>,  // 文件 -> 依赖
    reverse_edges: DashMap<String, Vec<String>>,  // 文件 -> 被依赖
    version_counter: AtomicU64,
}
```

主要方法：
- `add_dependency(from, to)` - 添加依赖
- `get_dependencies(file)` - 获取依赖
- `get_dependents(file)` - 获取被依赖
- `topological_sort(files)` - 拓扑排序
- `collect_transitive_dependents(file, max_depth)` - 收集传递依赖
- `has_cycle()` - 检测循环
- `find_all_cycles()` - 查找所有循环

用途：
- 热更新时确定需要重新处理的文件
- 确定文件处理顺序
- 检测和处理循环依赖

## 总结

Relation 模块采用分层架构，各模块职责清晰：

1. **Config Parser** - 解析构建配置，提取依赖
2. **Extraction** - 提取导入/导出，标准化表示
3. **Symbol** - 符号抽象，可见性模型
4. **Symbol Table** - 四层符号表，跨文件解析
5. **Module Graph** - 模块依赖图
6. **Index** - 关系索引，关系解析
7. **Query** - 高级查询 API
8. **Dependency Graph** - 文件依赖，热更新

各模块协同工作，提供完整的代码关系提取和查询能力。
