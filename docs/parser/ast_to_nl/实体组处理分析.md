# AST到自然语言转换 - 实体组处理分析

## 概述

本文档全面分析 AstToNl 转换器中实体组（EntityGroup）的处理流程，涵盖组类型、模式识别、模板分发、描述生成等环节。

## 模块架构

### 核心模块

| 模块 | 路径 | 职责 |
|------|------|------|
| 实体组转换 | `converter/group_converter.rs` | 实体组到 ConversionResult 的转换 |
| 单实体转换 | `converter/entity_converter.rs` | 单个实体到描述的转换 |
| 模式转换 | `converter/patterns/` | 各种模式的特定转换逻辑 |
| BM25 生成 | `bm25/generator.rs` | BM25 关键词优化文本生成 |
| BM25 模板 | `bm25/templates/` | BM25 模板（设计模式、样板模式、常规、标准库） |
| Embedding 生成 | `embedding/generator.rs` | Embedding 语义摘要生成 |
| Embedding 模板 | `embedding/templates/` | Embedding 模板 |
| 公共工具 | `common/` | 名称规范化、模板基类、辅助函数 |
| 分块器 | `chunker/` | 文本分块 |

### 数据流

```
EntityGroup[]
    │
    ├── AstToNlConverter.convert_entity_groups()
    │   ├── 插件优先处理
    │   └── 内置处理（组类型分发 → 模式分发 → 模板生成）
    │
    ├── 输出: GroupConversions[]
    │   ├── header_conversion: 组级描述
    │   └── member_conversions: 成员描述列表
    │
    └── GroupChunker.chunk_groups()
        └── 输出: ChunkedResult[]
```

## 实体组类型

### 基础实体组类型

| GroupType | 说明 | 处理方式 |
|-----------|------|---------|
| `ClassWithMethods` | 类及其方法 | 模式分发 + 压缩 |
| `InterfaceWithImpls` | 接口及其实现 | 接口描述 + 实现摘要 |
| `TraitWithImpls` | Trait 及其实现 | Trait 描述 + 实现摘要 |
| `RelatedFunctions` | 相关函数组 | 函数级描述 |
| `Standalone` | 独立实体 | 单实体描述 |
| `ModuleWithContents` | 模块及其内容 | 模块级摘要 |
| `TestSuiteWithCases` | 测试套件 | 测试用例描述 |

## 模式识别与转换

### 设计模式（10种）

| 模式 | PatternInfo 变体 | 识别特征 |
|------|-----------------|---------|
| Builder | `PatternInfo::Builder` | 包含 `build()` 方法和 `set_*` 方法 |
| Factory | `PatternInfo::Factory` | 包含 `create_*` / `make_*` 工厂方法 |
| GetterSetter | `PatternInfo::GetterSetter` | 大量 get/set 方法，少业务逻辑 |
| Singleton | `PatternInfo::Singleton` | 私有构造 + `get_instance()` 静态方法 |
| Strategy | `PatternInfo::Strategy` | 策略接口 + 多个实现 |
| Observer | `PatternInfo::Observer` | Subject + Observer 接口 + notify 方法 |
| Adapter | `PatternInfo::Adapter` | 适配器类，包装被适配者 |
| Decorator | `PatternInfo::Decorator` | 装饰器类，包装并扩展功能 |
| Composite | `PatternInfo::Composite` | 组合类 + 子组件管理 |
| TemplateMethod | `PatternInfo::TemplateMethod` | 抽象模板 + 子类实现步骤 |

### 样板模式（8种）

| 模式 | PatternInfo 变体 | 说明 |
|------|-----------------|------|
| Dto | `PatternInfo::Dto` | 数据传输对象，仅字段+getter/setter |
| Repository | `PatternInfo::Repository` | 数据仓储，CRUD 操作 |
| OrmEntity | `PatternInfo::OrmEntity` | ORM 实体，数据库映射 |
| Service | `PatternInfo::Service` | 业务服务层 |
| Config | `PatternInfo::Config` | 配置管理类 |
| Validator | `PatternInfo::Validator` | 数据验证器 |
| EventHandler | `PatternInfo::EventHandler` | 事件处理器 |
| GuiCallback | `PatternInfo::GuiCallback` | GUI 回调/监听器 |

## 模板分发机制

### 分发流程

```
GroupTemplateDispatcher.dispatch(group)
    │
    ├── PatternInfo::Builder(Summary)    → BuilderTemplate.generate_with_pattern()
    ├── PatternInfo::Factory(Summary)    → FactoryTemplate.generate_with_pattern()
    ├── ... 其他模式 ...
    ├── PatternInfo::None + is_stdlib    → StdlibGroupTemplate.generate()
    └── PatternInfo::None + 其他         → RegularGroupTemplate.generate()
```

### BM25 与 Embedding 模板对比

| 特性 | BM25 模板 | Embedding 模板 |
|------|-----------|---------------|
| 返回类型 | `String`（单个字符串） | `Vec<String>`（描述列表） |
| 原始名称 | ✓ 保留 | ✗ 移除 |
| 规范化名称 | ✓ 保留 | ✗ 移除 |
| 关键词 | ✓ 保留 | ✗ 移除 |
| 文档注释 | ✓ 保留 | ✓ 保留（核心意图） |
| 类型信息 | ✓ 保留 | ✗ 使用语义描述 |

## 转换流程

### 完整转换流程

```
1. AstToNlConverter::convert_entity_groups(groups, file_path, request)
    │
    ├── 1.1 检查插件注册表
    │   ├── 有匹配插件 → batch 处理
    │   └── 无匹配 → 逐个处理
    │
    ├── 1.2 对每个 group 调用 convert_entity_group()
    │   ├── 插件优先
    │   ├── 内置模式匹配
    │   │   ├── 按 GroupType 分发
    │   │   ├── pattern_dispatch! 宏
    │   │   └── 调用具体转换方法
    │   └── 生成 ConversionResult
    │
    └── 1.3 分离 header 和 member conversions
            ├── header_conversion: 第一个结果
            └── member_conversions: 剩余结果
```

## 输出模式

| 模式 | BM25 文本 | Embedding 文本 | 用途 |
|------|-----------|---------------|------|
| `Bm25` | ✅ 生成 | ❌ 空 | 关键词搜索 |
| `Embedding` | ❌ 空 | ✅ 生成 | 语义搜索 |
| `Both` | ✅ 生成 | ✅ 生成 | 混合搜索 |

| `include_signature` | `bool` | `true` | 包含函数签名 |

## 核心设计原则

1. **实体组导向**：以组为基本单位转换，保持上下文连贯
2. **样板压缩**：压缩样板代码到组描述，减少噪声向量
3. **双路输出**：同时支持 BM25 关键词和 Embedding 语义检索
4. **模式感知**：识别设计模式和样板模式，生成更精准的描述
5. **插件扩展**：支持外部插件自定义模板生成器
