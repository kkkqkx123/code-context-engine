# 数据流设计文档

## 一、完整数据流

### 1.1 索引流程

```
┌──────────────┐
│   Parser     │ 输出：ParsedFile { entities, local_calls, source, language }
└──────┬───────┘
       │
       ▼
┌──────────────┐
│  Grouper     │ 输出：Vec<EntityGroup>
└──────┬───────┘
       │ groups: Vec<EntityGroup>
       │   - 每个组包含 header + members
       │   - 包含 pattern_info
       │   - 包含 member_roles
       ▼
┌──────────────┐
│  AstToNl     │ 输出：Vec<GroupConversions>
└──────┬───────┘
       │ conversions: Vec<GroupConversions>
       │   - header_conversion: Option<ConversionResult>
       │   - member_conversions: Vec<ConversionResult>
       │   - 每个 ConversionResult 包含 bm25_text + embedding_text
       ▼
┌──────────────┐
│  Chunker     │ 输出：Vec<ChunkedResult>
└──────┬───────┘
       │ chunks: Vec<ChunkedResult>
       │   - 每个 chunk 包含 entity_ids
       │   - 包含 source_span
       ▼
┌──────────────┐
│  Embedder    │ 输出：Embeddings
└──────┬───────┘
       │ embeddings: Vec<Vec<f32>>
       │   - 与 chunks 一一对应
       ▼
┌──────────────┐
│   Store      │ 存储：Qdrant + BM25 + SQLite
└──────────────┘
       │
       ├─ Qdrant: 存储 vector + payload { chunk_id, entity_ids, file_path, start_line, end_line }
       ├─ BM25: 存储 document { chunk_id, content, entity_ids }
       └─ SQLite: 存储 EntityMapping { entity_id → chunk_ids }
```

### 1.2 热更新流程

#### 单文件热更新

```
文件变更触发（文件系统监控）
    │
    ├── Parser 重新解析文件
    ├── Grouper 重新分组
    ├── AstToNl 重新转换
    ├── Chunker 重新分块
    └── Store 更新（删除旧记录 + 插入新记录）
```

## 二、核心数据结构

### 2.1 EntityGroup

```rust
pub struct EntityGroup {
    pub group_id: String,
    pub group_type: GroupType,
    pub name: String,
    pub header_id: Option<EntityId>,
    pub members: Vec<GroupedEntity>,
    pub pattern_info: PatternInfo,
    pub member_roles: SmallVec<[(EntityId, MemberRole)]>,
    pub is_stdlib_group: bool,
    pub stdlib_category: Option<StdlibCategory>,
    pub language: String,
    pub context_hints: Vec<String>,
    pub span: Span,
    pub combined_source: Arc<str>,
}
```

### 2.2 ConversionResult

```rust
pub struct ConversionResult {
    pub source_entity_ids: Vec<EntityId>,
    pub source_span: Span,
    pub kind: EntityKind,
    pub name: String,
    pub file_path: String,
    pub bm25_text: Option<String>,
    pub embedding_text: Option<String>,
    pub raw_code: Option<String>,
    pub bm25_word_count: Option<usize>,
    pub embedding_tokens: Option<usize>,
    pub entity_metadata: Option<EntityMetadata>,
}
```

### 2.3 GroupConversions

```rust
pub struct GroupConversions {
    pub group: EntityGroup,
    pub header_conversion: Option<ConversionResult>,
    pub member_conversions: Vec<ConversionResult>,
}
```

### 2.4 ChunkedResult

```rust
pub struct ChunkedResult {

```

## 三、输出模式与存储

### 3.1 BM25 路径

| 步骤 | 输入 | 输出 | 存储 |
|------|------|------|------|
| 实体转换 | `EntityGroup` | `bm25_text: String` | BM25 索引 |
| 分块 | `ConversionResult` | `ChunkedResult.bm25_text` | BM25 文档集合 |
| 查询 | 查询字符串 | BM25 得分 | 倒排索引匹配 |

### 3.2 Embedding 路径

| 步骤 | 输入 | 输出 | 存储 |
|------|------|------|------|
| 实体转换 | `EntityGroup` | `embedding_text: Vec<String>` | - |
| 分块 | `ConversionResult` | `ChunkedResult.embedding_text` | - |
| 向量化 | `ChunkedResult` | `Vec<f32>` | Qdrant 向量库 |

## 四、查询流程

### 4.1 BM25 查询

```
用户查询
    │
    ├── BM25 索引搜索 → 返回匹配的 chunk IDs
    ├── 根据得分排序
    ├── 通过 EntityMapping 查找对应实体
    └── 返回结果（含源代码位置）
```

### 4.2 Embedding 查询

```
用户查询
    │
    ├── 查询向量化
    ├── Qdrant 向量搜索 → 返回匹配的 chunk IDs
    ├── 根据相似度排序
    ├── 通过 EntityMapping 查找对应实体
    └── 返回结果（含源代码位置）
```

### 4.3 混合查询

```
用户查询
    │
    ├── BM25 查询 + Embedding 查询
    ├── 结果融合（RRF / 加权平均）
    ├── 去重排序
    └── 返回最终结果
```
