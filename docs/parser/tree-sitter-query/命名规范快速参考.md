# 命名规范快速参考

## 格式速查

```
@[domain].[category].[subtype].[role].[attribute]
  ↑         ↑         ↑        ↑         ↑
 必填      必填      必填     必填     可选
```

## 常用捕获名称

### Entity Domain (@entity)

| 用途 | 捕获名称 |
|------|----------|
| 类名 | `@entity.type.class.name` |
| 类体 | `@entity.type.class.body` |
| 结构体名 | `@entity.type.struct.name` |
| 枚举名 | `@entity.type.enum.name` |
| 接口名 | `@entity.type.interface.name` |
| 函数定义名 | `@entity.function.definition.name` |
| 函数定义体 | `@entity.function.definition.body` |
| 函数参数 | `@entity.function.definition.params` |
| 函数返回类型 | `@entity.function.definition.return_type` |
| 方法定义名 | `@entity.method.definition.name` |
| 方法定义体 | `@entity.method.definition.body` |
| 构造函数名 | `@entity.function.constructor.name` |
| 析构函数名 | `@entity.function.destructor.name` |
| 变量声明名 | `@entity.variable.declaration.name` |
| 变量类型 | `@entity.variable.declaration.type` |
| 字段名 | `@entity.variable.field.name` |
| 字段类型 | `@entity.variable.field.type` |
| 参数名 | `@entity.variable.parameter.name` |
| 参数类型 | `@entity.variable.parameter.type` |
| 命名空间名 | `@entity.namespace.declaration.name` |
| 模板参数 | `@entity.template.params` |
| 宏名 | `@entity.preprocessor.macro.name` |

### Call Domain (@call)

| 用途 | 捕获名称 |
|------|----------|
| 直接函数调用名 | `@call.direct.function.name` |
| 直接函数参数 | `@call.direct.function.arguments` |
| 实例方法对象 | `@call.method.instance.object` |
| 实例方法名 | `@call.method.instance.function` |
| 静态方法类名 | `@call.method.static.class` |
| 静态方法名 | `@call.method.static.function` |
| 链式调用起点 | `@call.method.chained.from` |
| 链式调用终点 | `@call.method.chained.to` |
| 构造函数类型 | `@call.constructor.new.type` |
| 模板函数名 | `@call.template.function.name` |

### Dependency Domain (@dependency)

| 用途 | 捕获名称 |
|------|----------|
| 系统头文件路径 | `@dependency.include.system.path` |
| 本地头文件路径 | `@dependency.include.local.path` |
| using 命名空间名 | `@dependency.using.namespace.name` |
| #ifdef 宏名 | `@dependency.macro.ifdef.name` |

### Comment Domain (@comment)

| 用途 | 捕获名称 |
|------|----------|
| 单行注释 | `@comment.line` |
| 块注释 | `@comment.block` |
| 文档注释（Javadoc） | `@comment.doc` |

## 实际使用示例

### C 语言

```scheme
; 结构体定义
(struct_specifier
  name: (type_identifier) @entity.type.struct.name
  body: (field_declaration_list) @entity.type.struct.body
) @entity.type.struct

; 函数定义
(function_definition
  declarator: (function_declarator
    declarator: (identifier) @entity.function.definition.name
    parameters: (parameter_list) @entity.function.definition.params
  )
  body: (compound_statement) @entity.function.definition.body
) @entity.function.definition

; 函数调用
(call_expression
  function: (identifier) @call.direct.function.name
) @call.direct
```

### C# 语言

```scheme
; 类定义
(class_declaration
  name: (identifier) @entity.type.class.name
) @entity.type.class

; 方法定义
(method_declaration
  name: (identifier) @entity.method.definition.name
) @entity.method.definition

; 静态方法调用
(invocation_expression
  function: (member_access_expression
    expression: (identifier) @call.method.static.class
    name: (identifier) @call.method.static.function
  )
) @call.method.static
```

### C++ 语言

```scheme
; 模板类
(template_declaration
  parameters: (template_parameter_list) @entity.template.params
  (class_specifier
    name: (type_identifier) @entity.type.class.name
  )
) @entity.type.class

; 模板函数调用
(call_expression
  function: (identifier) @call.template.function.name
) @call.template.function
```

## Parser 使用示例

```rust
use code_context_engine::types::parser::{CaptureName, Domain};

// 解析捕获名称
let capture = CaptureName::parse("@entity.type.class.name").unwrap();

// 访问各部分
println!("Domain: {}", capture.domain);
println!("Category: {:?}", capture.category);
println!("Subtype: {:?}", capture.subtype);
println!("Role: {:?}", capture.role);

// 检查匹配
assert!(capture.matches(
    Domain::Entity,
    Some("type"),
    Some("class"),
    Some("name"),
    None
));

// 提取实体类型
if capture.domain == Domain::Entity {
    if let Some(category) = capture.category {
        println!("Entity category: {}", category);
    }
}
```

## 常见错误

### 错误格式

```rust
// ❌ 缺少 @ 前缀
CaptureName::parse("entity.type.class.name") // Error

// ❌ 缺少必要部分
CaptureName::parse("@entity") // Error

// ❌ 未知的 domain
CaptureName::parse("@unknown.type.name") // Error
```

### 正确格式

```rust
// ✅ 完整格式
CaptureName::parse("@entity.type.class.name") // OK

// ✅ 带属性
CaptureName::parse("@entity.type.class.qualified.name") // OK

// ✅ 最小格式
CaptureName::parse("@entity.type") // OK
```

## 验证工具

### 验证单个捕获

```rust
use code_context_engine::query::scheme::validate_capture_names;

let query = r#"
(class_declaration
  name: (identifier) @entity.type.class.name
) @entity.type.class
"#;

match validate_capture_names(query, "C#") {
    Ok(captures) => println!("Valid captures: {:?}", captures),
    Err(errors) => println!("Errors: {:?}", errors),
}
```

### 检查捕获类型

```rust
use code_context_engine::query::scheme::{is_entity_capture, is_call_capture};

let capture = "@entity.type.class.name";
assert!(is_entity_capture(capture));
assert!(!is_call_capture(capture));
```

### 提取实体类型

```rust
use code_context_engine::query::scheme::extract_entity_type;

let capture = "@entity.type.class.name";
let entity_type = extract_entity_type(capture);
assert_eq!(entity_type, Some("type".to_string()));
```

## 命名决策树

```
我要捕获什么？
├─ 实体定义 → @entity
│  ├─ 类型 → .type
│  │  ├─ 类 → .class.name
│  │  ├─ 结构体 → .struct.name
│  │  ├─ 枚举 → .enum.name
│  │  └─ 接口 → .interface.name
│  ├─ 函数 → .function
│  │  ├─ 定义 → .definition.name
│  │  └─ 原型 → .prototype.name
│  ├─ 方法 → .method
│  │  └─ 定义 → .definition.name
│  └─ 变量 → .variable
│     ├─ 声明 → .declaration.name
│     ├─ 字段 → .field.name
│     └─ 参数 → .parameter.name
├─ 调用关系 → @call
│  ├─ 直接 → .direct.function.name
│  ├─ 方法 → .method.instance.function
│  └─ 静态 → .method.static.function
├─ 依赖关系 → @dependency
│  ├─ 包含 → .include.system.path
│  └─ Using → .using.namespace.name
└─ 注释 → @comment
   └─ 单行 → .line.single.content
```
