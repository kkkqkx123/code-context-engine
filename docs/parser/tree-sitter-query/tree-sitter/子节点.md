在 Tree-sitter 的语法树中，**子节点是通过引用（指针）存储的**，而非完整数据的拷贝。类（`class`）节点和方法（`function`）节点是**独立存在的内存对象**，但通过父子关系（引用）形成层级结构。以下是详细说明：

---

### **1. 子节点的存储方式：引用而非拷贝**

- **内存效率**：Tree-sitter 的语法树设计为轻量级结构，子节点仅存储对父节点的引用（指针），而非重复存储整个子节点的数据。例如：
  - 一个 `class` 节点包含多个子节点（如 `field`、`method`），但这些子节点的数据（类型、位置等）仅存储一次，通过指针关联。
  - 修改子节点的属性（如位置信息）会直接影响所有引用它的父节点。

- **遍历效率**：通过引用关系（如 `ts_node_child()`）可以快速访问子节点，无需递归拷贝数据。

---

### **2. 类与方法节点的关系：独立存在但层级关联**

假设解析以下代码：

```python
class MyClass:
    def my_method(self):
        pass
```

Tree-sitter 生成的语法树结构如下（简化版）：

```
(class_definition
  name: (identifier)  # MyClass
  body: (class_body
    (function_definition  # 方法节点
      name: (identifier)  # my_method
      parameters: (parameters
        (identifier)  # self
      )
      body: (block)
    )
  )
)
```

- **独立性**：
  - `class_definition` 节点和 `function_definition` 节点是**独立的内存对象**，各自存储自己的类型、位置等信息。
  - 方法节点的数据（如方法名、参数列表）不会重复存储在类节点中。

- **层级关联**：
  - 类节点通过引用指向其子节点（如 `class_body`），而 `class_body` 再通过引用指向方法节点。
  - 可以通过 `ts_node_child()` 或 `TSTreeCursor` 遍历这种层级关系，例如：
    ```c
    TSNode class_node = ...;  // 获取类节点
    TSNode body_node = ts_node_child(class_node, 0);  // 获取类体（class_body）
    TSNode method_node = ts_node_child(body_node, 0);  // 获取方法（function_definition）
    ```

---

### **3. 关键设计优势**

1. **内存优化**：
   - 避免重复存储相同数据（如方法名在类节点和方法节点中各存一份）。
   - 适合处理大型代码文件（如数万行的代码库）。

2. **增量解析支持**：
   - 当修改代码（如添加一个方法）时，Tree-sitter 仅需更新受影响的节点及其引用关系，无需重建整个树。

3. **错误恢复鲁棒性**：
   - 即使类定义语法错误（如缺少冒号），方法节点仍会独立存在，仅通过引用关联到错误的类节点，确保其他功能（如方法高亮）不受影响。

---

### **4. 实际应用示例**

#### **场景：提取类中的所有方法名**

```c
#include <tree_sitter/api.h>

void extract_methods(TSNode class_node) {
    TSNode body_node = ts_node_child_by_field_name(class_node, "body");
    if (!body_node.id) return;  // 检查字段是否存在

    TSTreeCursor cursor = ts_tree_cursor_new(body_node);
    while (!ts_tree_cursor_is_null(&cursor)) {
        TSNode child = ts_tree_cursor_current_node(&cursor);
        if (ts_node_type(child) == "function_definition") {
            TSNode name_node = ts_node_child_by_field_name(child, "name");
            if (name_node.id) {
                const char *name = ts_node_string(name_node);
                printf("Method: %s\n", name);
            }
        }
        ts_tree_cursor_next(&cursor);
    }
    ts_tree_cursor_delete(&cursor);
}
```

- **说明**：
  - 通过 `ts_node_child_by_field_name` 直接访问类体的 `body` 字段，再遍历其中的方法节点。
  - 方法节点和类节点独立存储，但通过引用关联，无需手动维护层级关系。

---

### **总结**

- **子节点是引用**：Tree-sitter 通过指针关联父子节点，避免数据冗余。
- **节点独立存在**：类和方法节点是独立的内存对象，但通过层级引用形成树结构。
- **高效遍历**：通过 `ts_node_child()` 或字段访问函数（如 `child_by_field_name`）快速导航语法树。

这种设计既保证了内存效率，又支持灵活的语法分析和增量更新，是 Tree-sitter 适用于编辑器实时解析的核心原因。
