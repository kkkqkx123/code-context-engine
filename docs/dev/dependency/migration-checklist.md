# Bincode 到 Rkyv + Zstd 迁移检查清单

## 概述

本文档提供了从 Bincode 迁移到 Rkyv + Zstd 的详细检查清单，用于跟踪迁移进度和确保迁移质量。

---

## 阶段一：准备工作（1-2天）

### 1.1 依赖更新

- [ ] 更新 `cargo.toml`，添加 rkyv 依赖
  ```toml
  [dependencies]
  rkyv = { version = "0.7", features = ["validation", "size_32"] }
  zstd = "0.13"
  ```

- [ ] 保留 bincode 依赖（用于向后兼容）
  ```toml
  bincode = "1.3"  # 保留用于旧缓存数据
  ```

- [ ] 运行 `cargo build` 验证依赖更新成功

### 1.2 创建新的序列化工具模块
